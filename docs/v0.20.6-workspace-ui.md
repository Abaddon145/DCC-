# v0.20.6 专业创作界面测试版

## 范围

在已确认的中性石墨灰、克制琥珀色和高效率桌面布局方向下，复用现有 React 组件与 CSS 变量，不引入新的 UI 依赖。保留 v0.20 创作流程、数据及已取消的 UE 原生素材模块边界。

- 调整背景、面板、浮层、边框和字段层级；提高三种主题下小字说明的文字对比度。
- 统一工具栏、卡片、详情、项目、知识库、AI、设置、任务与弹窗的字号、间距和反馈。
- 工具栏按可用宽度换行；素材紧凑列表在内容区较窄时收起次要列，仍保留名称、缩略图、选择与收藏。
- 保留素材卡片尺寸及虚拟行高契约，不加入卡片拖动排序或缩放式悬停动效。媒体网格卡片限定在原有 236px 虚拟行内，列表仍使用 86px 行高。
- 媒体在数据首次异步加载完成后挂接宽度观察器，随窗口与侧栏宽度重算列数。
- 侧栏底部按钮样式仅作用于直接导航按钮，避免任务中心标题、关闭按钮和操作按钮被整行宽度挤压。
- 笔记本操作保留完整功能，模板选择不再被挤成单字；保留自定义笔记导航颜色、正文颜色、正文独立字号和常驻视图切换。
- 入场、按下、加载和抽屉采用轻量反馈；系统或用户选择减少动画时关闭动画与过渡。

不升级数据库 schema，不重新分类历史素材，不改变在线翻译、额度、Epic 路由、浏览器采集或文件读写权限。没有上传素材、调用在线翻译或修改用户素材库来测试界面。

## 参考与取舍

独立整理共享视觉规则，参考 [Spacedrive](https://github.com/spacedriveapp/spacedrive) 的内容检索与详情分层、[AFFiNE](https://github.com/toeverything/AFFiNE) 的知识工作区控件组织；不复制实现或引入它们的业务框架。采用 ui-ux-pro-max 的可读性与桌面交互指导，通过 grill-me 确认范围；不使用营销页面式装饰替换高密度工具界面。

## 安装后验收

1. 安装测试包并确认设置中显示 0.20.6；关闭并重新打开，核对原素材库、项目、笔记与媒体仍在。
2. 依次打开素材详情、媒体详情、项目、知识库、AI 和任务中心；调整窗口与侧栏，核对工具栏没有遮挡、按钮可点击、列表没有上下重叠。
3. 切换三种主题，调整强调色、密度、90–125% 字号和减少动画；核对设置保留，键盘焦点可见。
4. 打开已有彩色笔记，核对导航色和正文独立外观；核对编辑/阅读/大纲/导图切换与笔记拖拽未改变。
5. 使用真实素材回归 Fab 单条/批量导入、补齐双语、Epic 商品定位、模型预览、浏览器采集、参考板、回收站与备份。在线操作仍按原确认流程执行并产生服务商额度。

验收前保留草稿 PR，不合并或创建正式 Release，不自动安装或退出正在使用的软件。
