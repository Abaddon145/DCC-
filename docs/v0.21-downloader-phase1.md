## 2. 新增模块

- Downloader：URL/平台识别、参数验证、元数据/格式/进度解析、Cookie 和完整下载后入库流程。
- Runtime：固定工具检测、哈希核验、磁盘空间预检、直接参数调用。Windows 子进程先挂入 kill-on-close Job Object 再启动，取消时结束整个进程树；不开放 shell、任意参数、用户配置或插件入口。
- Media engine：严格 ffprobe 分析有效视频/音频流，读取时长、尺寸、编码、帧率和容器；沿用现有媒体处理生成缩略图、波形和必要代理。
- 下载由既有 `TaskRequest::Download` 管理，没有另建独立任务队列；保留 `tasks.rs` 的既有接口，没有为目录形式搬迁全部任务系统。

## 4. 数据库与安全

当前实际 schema 为 19，本次最小增量升级到 **20**，不是重建旧版媒体表。

- `download_tasks`：`id/task_id/url/title/platform/status/created_at/finished_at`。
- `media_sources`：`id/media_id/platform/url/title/author/download_task_id/created_at`，外键关联现有媒体与下载记录，同一媒体/任务组合防重复。
- 所有下载仍写入现有 `media_entries/media_files`，不创建独立媒体库。重复内容复用已有条目，追加来源；回收站重复要求先恢复或清理。
- 托管字幕采用已有 `media_files` 的 dependency 角色，随现有整库备份保留。备份包含来源表、媒体原件、代理、缩略图和字幕，不包含下载授权 Cookie。
- 全局下载设置沿用原设置文件，新增字段有默认值；旧设置、模块顺序和任务记录可继续读取。
- Cookie 内容用 DPAPI 加密，Windows 凭据管理器只保存随机标识。yt-dlp 执行期间使用临时明文文件，正常结束自动删除；活跃文件持有禁止删除的句柄，重启/使用/删除凭据时独占检查并清除异常退出遗留文件。异常断电后，清理发生在下次启动，不能声称从未产生临时明文。
- 下载工作区限制为当前库 `.dcc/runtime/downloads/<task UUID>/`；已下载文件先验证，再复用安全导入。另存使用临时文件、空间检查、可取消复制和原子不覆盖提交，重名使用 `(1)` 等后缀。
- 并行网络下载允许 1–4 项；校验后入库串行，避免相同文件竞态，其他既有任务保持原执行约束。

## 5. UI 与使用方式

1. 侧栏进入“下载中心”，输入有权下载的公开 HTTP/HTTPS 链接并解析。
2. 查看标题、封面、作者、时长、可用格式和字幕语言。封面由后端安全读取，不放宽全局 CSP。
3. 选择视频或 MP3 音频、最佳/不超过 1080P/720P、具体格式、是否同时下载可用字幕，以及仅入库或入库后另存。
4. 播放列表先勾选条目，再加入现有任务队列。下载中心和任务中心均可查看进度、暂停、恢复、取消及重试；关闭页面不会停止后台任务。
5. 下载完成不直接报成功：先校验、probe、处理并入库。完成项提供“查看媒体库”；媒体详情显示尺寸/时长和来源网页入口。
6. 设置中心新增“下载”页，管理另存目录、并发、代理、Cookie 来源、默认质量和四项工具状态。

沿用 DCC 主题和组件，没有整体改版。未知总量使用不确定进度；入库阶段不继续显示过期网络速度或 100% 下载进度；加载控件尊重减少动画设置。

暂停是停止子进程并保留 `.part`，恢复使用 yt-dlp `--continue`；是否断点续传取决于源站，不宣称所有站点都能原地恢复。任务跨库隔离，不能在另一库继续原库的下载。

## 8. 已知限制与未完成实机验收

- 未使用真实 YouTube/B站账号、Cookie 或付费内容进行联网验收；站点、风控、DRM、登录和网络条件会影响下载。DRM 内容不支持，不保证任意网站都可下载。
- 未在干净 Windows 10/11 虚拟机进行安装/升级测试，未改动用户当前安装、默认库或真实凭据；已核对生成的 NSIS 清单包含四项工具、许可证和简体中文。
- 浏览器 Cookie 读取由 yt-dlp 处理；新版 Chrome/Edge 的加密、浏览器占用与权限可能导致失败，可用显式导入的授权 Netscape Cookie 替代，仍需实机核对。
- 播放列表解析最多 500 条，不递归下载整站；字幕作为随附文件保留，不提供字幕编辑或仅字幕独立素材入口。仅音频当前输出 MP3。
- 空间预检和工具错误分类已测试，但没有实际填满用户磁盘或修改用户权限进行破坏性测试；源站不报告大小时无法预知最终占用。
- 完成/取消下载的工作区保留，方便恢复、重试与打开输出；本阶段不自动清理，长期使用会占用额外空间。整库备份托管媒体，不包含未完成工作区。
- 未提供 yt-dlp 自动更新；版本固定并校验完整性，站点变更需要受控更新工具清单。yt-dlp 打包组合为 GPLv3+；随包附许可证及上游链接，但完整对应源码分发义务的发布审计尚未执行，不能把本次本地构建当作公开 Release 合规验收。
- 构建中的原有大 JS chunk 提示、既有 `knowledge::search` 未使用提示和 MSVC 链接器提示不是构建失败，未借本次重构无关模块。
