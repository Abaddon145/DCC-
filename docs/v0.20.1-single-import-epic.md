# v0.20.1 单条自动补译与 Epic 工程添加（测试版）

基线为 v0.20.0 `fcc830c324f4b9f91c22b80b6c02a16f5d85fe98`，不恢复用户取消的 v0.21 UE 原生素材模块，不升级素材库 schema。

## 自动补译与归类

新建素材的手工录入、快速录入与 Fab 录入使用同一个保存入口。只补空白双语字段，使用现有服务优先级、专业术语、缓存和月度额度；未配置或调用失败仍保留可用原文，返回待处理警告。编辑历史素材仍尊重用户明确编辑；批量补译保持原入口。

Fab 新建保存尊重“Fab 自动翻译”开关；关闭时不调用付费翻译，保留原文并提示待补译。保存请求必须携带表单所属素材库 UUID，切库会关闭旧表单；读取和每个翻译方向开始前、最终写入前再次验证，防止旧表单写入新库或继续请求。显式读取新的 Fab 商品时同步规范化来源网址，后端拒绝来源与商品 ID 不一致的提交。

有效 Fab 商品 URL 且未手动分类时，采用已有官方分类映射。分类在素材写入事务内创建，失败不遗留空分类；无 Fab 来源不猜测分类。Fab 表单读取只填元数据，自动翻译统一在新建保存时完成，避免重复请求与迟到响应覆盖。

## 任务历史兼容

曾安装 v0.21 的机器可能在全局 task-journal.json 中留下 `ueAssets` 请求。v0.20 原枚举无法读取这些记录，导致整个任务中心拒绝提交新的补译任务。本补丁保留其原始请求与历史，仅展示为旧版只读记录；不允许提交、重试或执行。其他未知任务或损坏 JSON 仍保持原来的阻断保护，不能借兼容逻辑静默丢弃数据。

不会修改实际用户任务记录来绕过问题。测试使用独立临时目录，涵盖正常翻译任务与旧 UE 记录共存、保存后原始 UE 内容不变以及禁止重试。

## 通过 Epic 添加到 UE 工程

1. 打开含有效 Fab 来源的素材详情，点击“通过 Epic 添加到 UE 工程”。无需本地素材原件。
2. 选择创作项目中已登记的 `.uproject`，或通过原生文件选择器指定工程。只读取有大小限制的工程 JSON 和 EngineAssociation，不修改工程、不扫描磁盘。
3. 版本候选来自 Fab 的 Unreal Engine 格式信息，不从手填素材版本推断。同版优先；旧素材版本可用于更新工程，但显示风险提示；高于工程的版本不允许继续。
4. 官方版本缺失、网络失败或自定义引擎无法确认时，明确提示手动核对，不凭空补版本。
5. 打开 Epic 商品入口后，在 Epic 中再次核对版本与目标工程，完成“添加到项目”“创建工程”或“安装插件”。

**限制：** 本应用不能承诺直接跳过 Epic 的购买验证、工程/版本确认或开始下载。使用已购素材的 Epic 登录账号；不读取密码、Cookie、Token、Vault 或账户。工程路径与版本不会作为未经文档支持的 Launcher 启动参数传递。仅从当前库已保存的 Fab 商品 UUID 构造固定协议地址。

最近成功打开时的工程与版本使用按素材库 UUID 隔离的本机 UI 偏好保存；关闭“记忆工作区”时不读写此偏好。该偏好不包含账户信息、不进入素材库备份，切库会关闭弹窗并丢弃迟到响应。
