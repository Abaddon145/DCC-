# SQLite 课程迁入生产闭环

沿用已批准 Task12/M6A 和 Task13 的单应用、来源选择和不覆盖规则。用户本次要求先以合成数据验证生产预检、提交及撤回，不合 main。

1. 新增 Windows 离线源快照：固定目录和 DB/WAL/SHM 文件身份，拒绝活动写连接、回滚日志、链接、缺失侧文件或总大小超限；只复制文件，SQLite 仅打开隔离副本。检查 schema8、完整性和外键，设置 SQL 校验时限，返回时仍持源租约。
2. 在现有来源会话中保存一次性、15 分钟、仅本进程有效的预检批准，绑定 scope/profile/epoch/selection 和源、目标指纹。选择与撤销通过同一短操作锁和最终提交互斥。预检不写业务目标；媒体仅显式绑定已有媒体 UUID，不从源路径授权。
3. 新增 commitCourse 任务，只接受选择和预检 UUID，经专用命令排队。Worker 重新复制和核对来源及目标，复用 stage_course_batch/commit_course_batch 和现有撤回；过期、取消、重启、切库、重新选择及变化均要求重新预检。通用入口/重试不能绕过批准。
4. 前端展示课程、显式媒体绑定、双方进度与冲突，修改绑定使预检失效，确认后排队；任务中心展示提交回执，终态刷新批次。现有撤回 UI 复用。
5. 先复现缺失行为，再验证闭环、WAL、源字节不变、并发写拒绝、源/目标变化、撤销/切库、取消、重复排队及重启失效。执行相关全量测试、生产编译和独立只读审阅，保留验证边界。

首版明确要求关闭源软件。不实现运行中源 SQLite 直接连接，不开放前端任意路径，不读取用户真实数据库来代替合成测试。现有 dirty 工作保留，不安装、不发布、不合 main。
