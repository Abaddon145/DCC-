# DCC v0.23 Asset Intelligence Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不破坏 v0.22 的情况下，让普通素材、媒体、Prompt 和 Shot 形成可分析、检索及关联项目的创作资产网络。

**Architecture:** 继续使用 `asset_core` UUID、旧来源表、共享词库与 `LibraryTask`。关系和分析是核心身份上的扩展；文本资产只扩展核心来源约束；Shot 连接已有 `project_units`。联网只发生在用户确认分析资料之后。

**Tech Stack:** Rust 2021 / Tauri 2 / rusqlite / React 19 / TypeScript / Vitest；复用 image、base64、sha2、FFmpeg 与 DeepSeek，不增加图布局或向量数据库依赖。

**Spec:** `docs/superpowers/specs/2026-10-11-v0.23-asset-intelligence-design.md`（用户已确认）。

## Global Constraints

- 应用目标 `v0.23.0`；完整版本 schema `21 → 22`。开发中的各 Phase 不作为独立正式版本发布。
- 保留旧核心 UUID、来源 ID、AssetFile、物理原件与旧模块；不重写素材库/AI助手/项目/任务队列。
- 顺序为 Phase 1 Relations → Phase 2 Analysis → Phase 3 Search → Phase 4 Prompt → Phase 5 Shot。
- 所有新命令检查 `expectedLibraryId`；UUID、枚举、长度及所有权检查在后端；网络请求期间不持有素材库锁。
- 禁止自动生成视频、剪辑、完整聊天、自动镜头识别、复杂向量数据库、UE完整资产管理。
- 真实服务/凭据不用于 CI；GitHub 发布不包含在本次实现授权中。
- 关系图每页最多 80 个邻居；统一搜索每页最多 200 项；embedding 最多 4096 维且全部为有限数值。
- Prompt 内容最多 100,000 字；名称 200 字、模型名 200 字、JSON parameters 16 KiB；Shot ACT/编号各 80 字，描述 10,000 字。
- 新 TS 模型放在 `src/features/intelligence/types.ts`，Rust 模型放在 `asset/intelligence_models.rs`；外部结构采用 camelCase、拒绝未知输入字段。

## Review Focus

1. 已保存版本的旧资产迁移时 UUID、文件引用和清理触发器不能改变；外键开关在成功与失败后都恢复（Task 5）。
2. 用户确认后原件被替换、资料修改或切库，排队与迟到 AI 响应不能发送/写入新的未确认内容（Tasks 2–3）。
3. 增加 AI 标签时另一操作已修改标签，不能用旧快照覆盖；清理普通素材不能删除仅被 Prompt 使用的词库标签（Tasks 3、5）。
4. 项目/镜头删除与 Shot 删除不能连带删除参考素材、Prompt、媒体；旧项目入口修改镜头后不能显示互相冲突的资料（Task 6）。
5. 图与搜索遇到 10,001 项、高连接度、空字段、引号及 SQL 通配字符，必须限定结果、保持条件和数据归属（Tasks 1、4、7）。
