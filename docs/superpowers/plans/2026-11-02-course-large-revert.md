# 大课程系列迁入与撤回

沿用现有离线快照、显式媒体绑定和同一事务撤回；不能拆散系列并误写来源身份。当前每批 400 项限制来自旧撤回报告 64 KiB 上限。

1. 用 600 项合成单系列复现预检或撤回失败，保留原有 400 项回归。
2. 将撤回报告持久存储的单条上限由 64 KiB 扩展到 2 MiB，事务内与撤回一并写入；旧报告继续读取，损坏报告明确报错，保留来源与目标。增量 schema 升级必须可回滚、备份恢复后可读。当前 10,000 项和既有 1 MiB 暂存限额下，使用单条报告比额外分块表更简单；若进一步提高规模，应改为分块或逐项持久化。
3. 扩大安全可验证的单批上限；预检仍检查待暂存数据上限。列表、任务中心和分页明细正确展示完整报告，不能截断或伪造数量；大报告界面分页。
4. 合成验证 600 项提交/撤回、重试回执、备份恢复、迁移失败回滚和已有旧报告。运行后端与前端回归，单独报告源上限及桌面/真实数据库未验证范围。不合 main。
