# DCC v0.22 Asset Core 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不替换旧数据与入口的前提下实现统一资产身份、目录扫描、多文件与版本、来源汇总、浏览及下载登记。

**Architecture:** `asset` 深模块适配旧 assets/media_entries，而不是复制第二份可编辑基本信息。新增核心登记与文件引用、元数据、来源、版本表；文件内容仍由原托管系统负责。任务、预览协议、标签、项目和下载复用已有实现。

**Tech Stack:** Rust、rusqlite、serde、uuid、已有 image/WalkDir/FFmpeg/FFprobe；React 19、TypeScript、已有 React Virtual、Vitest；Windows x64 Tauri/中文 NSIS。

**Spec:** `docs/superpowers/specs/2026-10-11-v0.22-asset-core-design.md`（用户已确认）。

## Global Constraints

- 应用版本 v0.22.0，增量数据库 schema 20→21；备份容器格式不改。
- 不替换已有 assets/tags，不变更旧 ID、协议 URL、文件位置和笔记引用。
- 保留四媒体库、Fab/双语、项目、知识库、参考板、回收站、下载；不删除旧功能。
- 禁止 AI 分析/自动语义标签、向量搜索、Prompt 系统、剪辑、自动镜头识别、UE 完整资产浏览。
- 不重做整体 UI，不增加大型依赖，不修改映流仓库。
- 先登记旧记录；迁移不进行全库哈希、ffprobe 或缩略图重建。
- 新命令必传 expectedLibraryId，后台任务绑定创建时素材库；切库后旧响应不能污染新视图。
- 不自动推送、合并或发布 GitHub；旧工作区改动单独保留，阶段提交不能混入无关改动。

## Review Focus

1. 普通素材与媒体可能拥有相同旧 UUID：两个核心身份仍需独立、稳定，不覆盖旧引用。（Task 1 测试）
2. 旧详情删除图片或回收站清空可能绕过版本保护：其他资产引用的原件不能被删除。（Task 1、5 测试）
3. 清理普通素材后只被媒体使用的共享标签：标签、颜色及媒体关系必须保留。（Task 4 测试）
4. 扫描时文件被替换、目录是 junction、切库后继续导入：拒绝越界，重新校验，不能跨库写入。（Task 2 测试）
5. 下载已入媒体库但核心登记失败：重试不重复下载/复制，不丢来源和字幕。（Task 6 测试）

## 文件与接口约定

- 新增 `src-tauri/src/asset/{mod.rs,models.rs,schema.sql,repository.rs,service.rs,scanner.rs,metadata.rs,commands.rs,tests.rs}`。
- 新增 `src-tauri/src/media_engine/thumbnail.rs`；复用原图片/媒体处理器，不平行实现。
- 新增 `src/features/assets/{api.ts,types.ts,AssetBrowser.tsx,AssetCard.tsx,AssetDetail.tsx,TagPanel.tsx,SourcePanel.tsx,VersionPanel.tsx,assets.css}` 及对应测试。
- 修改 `db.rs`、`media_library.rs`、`media.rs`、`tasks.rs`、`lib.rs`、`backup.rs`、`organization.rs`、`App.tsx`；在 Task 6 才修改下载登记与版本清单。
- 所有核心 Rust 公开接口使用 `Result<T, String>`，serde camelCase、严格输入字段；不重命名旧前端 AssetCard/AssetDetail 类型。
- `CoreOrigin` 为 `{ kind: legacy|media, id: UUID }`；核心 `Asset.id` 是新登记 UUID，`origin` 保留旧 ID。
- `SourceFileRef` 为 `{ kind: image|assetMedia|mediaFile, id: UUID, role: String }`。同一旧图片/附件的原件与缩略图必须通过 role 区分。
- `AssetFile` 包含核心文件 UUID、assetId、sourceRef、role、filename、extension、size、hash、createdAt、available；前端不获任意磁盘读取能力。
- `AssetMetadata` 包含 fileId、可空 width/height/duration/codec/fps；原件无分析结果时保留空值。
- `Asset` 基本字段包括 name、assetType、description、thumbnail、tags、createdAt、updatedAt、origin、deleted；均读取原表。
- `CoreAssetDetail` 增加 files、metadata、sources、versions、projects、knowledgeLinks、relatedAssets、processingHistory。
- `CoreSearchRequest` 包含 query、assetType、source、locale、offset、limit；默认 limit=80，最大 200，排序 updatedAt DESC/id，未知筛选值报错，不扩大结果。
- 核心文件绑定现有托管所有者。追加文件先安全导入再登记引用，不另复制；版本只引用原件，不选可重建代理/缩略图。
