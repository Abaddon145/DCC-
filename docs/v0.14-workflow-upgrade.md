# v0.14.0 工作流升级与验收

## 已确认范围

修复现有交互、跨筛选多选提示、库级工作区上下文、统一任务中心、媒体关联项目与图片参考板。保持取消的合集/评分/网盘保存助手不出现。GitHub 目标为 Abaddon145/DCC- 私有仓库。先测试安装包、Windows 验收后才合并/Release。

## 数据与安全

- 工作区上下文保存在现有库级偏好 JSON，按模块分别写入，带活动库 UUID 验证，不保存编辑草稿和多选。
- 任务记录保存在固定设置目录 task-journal.json，绑定库 UUID。进程重启后未完成任务标为 interrupted，只有用户明确重试才执行。
- 媒体导入文件处理不占用活动库长事务，单条完成后短事务写入。停止保留已提交条目，清理未提交的暂存目录；FFmpeg/FFprobe 均有超时与子进程回收。
- 备份流式校验，压缩使用独立连接；维护期间通过统一命令入口拦截写入。恢复与迁移暂停新读取以避免读到新旧文件混合状态。
- 恢复先验证 ZIP 清单与数据库，准备新目录，创建 safety-backups 安全副本，逐项原子改名；失败回滚。不可回滚时保留原库目录并报告路径。
- 任务结果只在选中任务时读取，界面每页最多 100 行；日志不包含翻译密钥或签名。凭据、个人素材库和安装产物不提交 Git。

## 尚需实机验证 / 限制

- Windows 10/11 WebView2 下实际大 GLB 的材质、缩略图、任务期间切换模块及释放 WebGL 上下文。
- 大型视频/音频处理中停止、关闭确认、重新启动手动恢复；20,000 条素材跨筛选全选与批量操作。
- 备份期间检索、恢复/迁移维护提示、低磁盘空间、权限失败、跨盘迁移和安全副本恢复。
- 浏览历史当前为模块前进/后退；同一模块内的每一步筛选/文件夹变更还不是独立历史条目。
- 参考板、标签管理等模块现有内部编辑状态未纳入工作区上下文；未完成表单不持久化。
- 恢复/迁移的任务阶段为安全维护提示，逐文件进度仅在备份/导入可见。

## v0.14.1 导入回归修复

用户截图报 “Execute returned results - did you mean to call query?”。测试先通过实际后台连接入口复现相同错误，再验证 SQLite 超时赋值返回结果行。修复为 Connection::busy_timeout；保留外键开启和 5 秒等待。模型/图片导入、重复跳过、活动连接可见性均加入测试。无需数据库迁移，不清理现有库。测试安装包重新编号 v0.14.1，旧失败任务不会自动重试。
