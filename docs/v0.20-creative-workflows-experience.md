# v0.20.0 创作流程与体验修复

## 本次范围

依据 Q1–Q9 的 A 方案实施，延续现有导航、深色主题及琥珀色强调色。不新增 AI 供应商、自动付费重试、云同步或媒体复制服务。复用已有拖动、加载反馈、事务及素材库 UUID 校验；无新增 npm 或 Rust 依赖。

本次保留并包含 v0.19.2 的 `browserCapture` 工作区模块注册修复。该修复此前已形成独立本地基线提交，上传时保留可追溯来源。

## AI 请求与错误恢复

- 创作方案、整理、自然语言检索、项目选材采用各自的响应结构。缺少不相关数组允许默认空值；出现非空越界字段、未知 ID 或禁止修改的事实字段仍拒绝。
- 创作方案只包含要求及明确选中的文字元数据/项目资料；仅整理请求附带分类、文件夹和标签字典。不会发送媒体文件、网盘链接/提取码、系统路径或服务凭据。
- 准备时保存完整消息快照，确认生成使用同一快照；升级后打开历史草稿不重新编造原始发送文字。旧版本未记录快照的历史请求明确显示“只显示历史上下文”，不会声称它是原始消息。
- 展开“完整发送范围”可检查全部消息。准备及重新准备不联网；确认发送才调用 DeepSeek；逐项检查后另行确认应用。
- 越界拒绝提示列出对应字段，例如 `changes`。不静默丢弃这些字段，不将未经校验的局部结果应用到素材库。
- 本机保守预留与本次服务返回 Token 分开显示。结果未完整生成或本地校验失败时，已返回的服务用量仍保留；缓存命中为 0。无法确认的请求保留预留值，该计数不是服务商账单或余额。
- 保留现有临时 HTTP 服务错误最多一次重试；鉴权、取消、不完整结果、结构或业务校验失败不会自动再次请求。失败后的“重新准备请求”仍须重新确认发送。

截图中的原始 AI 响应此前未保存，不能逐字重放或保证远端模型永远返回合规结果。本次使用本地模拟响应与确定性测试验证合约、拒绝边界及恢复行为，没有调用真实付费 AI 服务。

## 工作流程模板

入口：创作项目 → 打开工作区 → 任务 → 工作流程模板。

- 可选交付检查或 UE5 场景制作预设，再保存本库命名模板。
- 模板为 1–30 个有序任务标题；可新增、编辑、删除、拖动排序，也可用上移/下移按钮完成键盘排序。
- 可修改原模板、另存新模板或确认删除。删除模板不会删除项目任务。
- 勾选预览后追加到当前项目的待办列；已有同名任务跳过，原有任务的状态、说明和排序不被重写。
- 模板属于当前素材库，随数据库备份、恢复及迁移保存；所有写操作校验素材库 UUID，拒绝旧窗口写入已切换的库。

应用升级至 0.20.0；内部数据库版本从 18 升至 19，增加 `workflow_templates` 和 `ai_sessions.actual_tokens`。迁移可重复执行且保留已有数据，不修改外部工程或媒体原件。

## 图片 A/B 对比

- 图片库多选恰好两项后点击“对比两张图片”；或右键图片“加入图片 A/B 对比”。
- 素材详情/媒体查看器的图片预览可点击“加入 A/B 对比”；待选栏满两张后开始对比。同一图片不能充当两项。
- 并排查看或按 A/B 单图切换；滚轮以光标为中心缩放，左键拖动同步平移，工具栏可缩放和适应窗口，双击也可恢复适应。
- 缩放 25%–800%；键盘 A/B、加减、0、Escape 可切换、缩放、复位和关闭。
- 工具栏位于视口外；读取失败显示重试。只使用当前库登记的图片 UUID，不接受磁盘路径，不复制图片，不处理音视频比较。
- 同步的是各图适应窗口后的相对缩放与归一化平移；不是不同原始尺寸图片的逐像素配准。退出释放视图，切库清空待选。

## 稳定性及交互

- 参考板列表读取失败不再伪装为空库；支持重试、保留已有列表，旧打开响应不能覆盖较新的选择。返回列表、创建、复制、删除时使旧打开请求失效。
- 项目、场景/镜头和任务保存阻止连点重复提交；写入失败保留编辑草稿。主参考板切换、解除关联、删除路径的失败会提示，不再静默忽略。
- 任务看板与镜头视频选择器增加读取失败重试，避免把错误当成无结果。
- 命令面板支持焦点保持、Tab 约束、Escape 关闭和关闭后恢复触发点；弹层内按键不触发背景普通应用快捷键。流程模板和对比弹层也提供基础键盘焦点保护。
- 短时入场、按压及加载反馈使用现有 CSS；不显示虚假进度。沿用“减少动画”设置，并响应系统减少动态效果，禁用循环动画而非将它们加速。

视觉方向：密集桌面创作工具，设计变化 3/10、动效 4/10、信息密度 6/10。保留品牌和熟悉的工作路径，只改善状态层次、固定工具栏、响应式排布及焦点。
