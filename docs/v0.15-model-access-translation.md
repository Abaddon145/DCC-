# v0.15 模型文件与备用翻译

## 模型使用

三维模型库的详情与单项右键菜单提供“在资源管理器中显示”和“导出模型包”。定位的是素材库托管原件，不依赖导入前的位置。导出选择工作目录后创建一个新子目录，重复导出自动加序号，不合并已有目录。

导出从数据库读取主文件和已托管依赖，保留 glTF、OBJ 相对目录关系；不包含代理或缩略图。缺失依赖或越界路径会中止，并清理未完成的临时目录。现有 FBX 导入按单文件处理，未曾收录的外部贴图不在模型包中。

## 在线翻译

- 默认 DeepSeek 优先、百度备用，可调整顺序或关闭故障切换。
- DeepSeek 使用固定官方 HTTPS 地址与 deepseek-flash，非思考模式和严格 JSON 输出；不提供自定义服务地址。
- 余额不足、频率限制、临时网络/服务异常可使用备用服务。DeepSeek 临时错误最多重试一次；额度故障在本进程内暂缓 30 分钟，临时故障暂缓 60 秒，避免逐字段重复请求。更新凭据或测试连接可清除暂缓状态。
- 鉴权、参数错误不会偷偷改用其他服务。达到 DeepSeek 本机限额时暂停当前请求，不通过备用服务绕过此限额。
- 模型名称、描述、标签与许可仍通过现有专业术语层，品牌、链接、路径和代码标识符在本地保护。
- 成功片段缓存按提供商、模型、提示版本、语言方向和源文区分。术语重组在缓存之后，调整词库后仍生效。缓存不保存 API Key 或请求签名。
- 手动编辑显示文字与 Token 粗略估计，批量补译在确认中显示待译估计。Fab 批量导入需先读取元数据，再显示当前行预估。
- 月度默认上限为 1,000,000 Token，记录在当前电脑。发送前按请求体及最大输出保守预留，响应成功后按 total_tokens 结算。请求结果不明时保留预留值；达到上限后剩余字段待补译。测试连接不使用缓存，也遵守限额。
- API 用量与付费由用户自己的服务账户承担。这里的计数不等于服务商余额，百度字符记录不包含内部重试。每月重新计数；清空缓存不会重置用量。

主窗口设置、词库和缓存跨素材库共享；凭据只存 Windows 凭据管理器。缓存、月度记录和凭据不随素材库备份或迁移。

自动化覆盖模型复制与依赖、中文和 Windows 路径、目标冲突、回收站、越界路径、缓存跨重启、服务故障切换、鉴权停止、月度预留与结算、上限阻止请求、凭据界面和导出取消。测试不调用真实翻译服务、不消耗账户额度。

Windows 实机待验证：

1. 在资源管理器中选中包含空格/中文名称的模型。
2. 导出 glTF/OBJ 模型包，在目标 DCC 中确认材质与依赖正确。
3. 配置用户自己的 DeepSeek API Key，测试连接并翻译一个 Fab 条目。
4. 验证已有中文不被自动覆盖，以及当前百度额度不足时的备用服务表现。
5. 覆盖安装、重启保留优先级/用量/缓存，原素材库正常打开。
