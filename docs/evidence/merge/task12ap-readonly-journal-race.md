# 合成快照回滚日志复核

2026-11-01。测试专用的跨进程合成快照会话在回调前后检查回滚日志：存在或无法确认不存在时拒绝结果。回调前已有日志时不会启动回调；回调期间创建且结束时仍存在的日志会使结果被丢弃。
