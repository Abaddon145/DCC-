# Task8.5：课程分析面板检查点

2026-10-24；基线c2fa217。学习工作区增加课程分析面板，延续现有主题/加载反馈/播放器控制，不重做整体UI，不增加依赖。本文区分组件模拟、真实桌面与付费服务，不将合成结果当作原用户个案或真实AI产物。

## 功能与数据

- 选择已有字幕和明确的采样秒数，先预览阶段范围、来源、缓存和Token上限；独立勾选发送/费用确认后才可提交同一TaskRegistry。预览过期、资料改变和类型不符均不能沿用旧批准。不会自动转写、下载Whisper模型或写笔记。
- 用原生表单、按钮、progress与现有LoadFeedback显示校验/排队/执行/错误；未知总量时不显示假百分比。关闭面板不取消任务，取消为明确操作，失败继续需重新预览。
- 新`list_course_analyses`只读取本库课程的有界历史元数据，不读取大result_json；历史、阶段和费用预览均每页最多50项。原`get_course_analysis`按需返回单个有界结果。历史不受任务中心最近200条完成记录的显示范围限制。
- 详情增加可核验`parentAnalysisId`，取自本机不可变快照；重试部分汇总使用真正父结果，而非将部分汇总当作下一层父结果。前端不能提交谱系计数、结果或任意文件路径。
- 章节、重点、步骤、术语、用途、练习和本机校验报告为纯文本；经后端核验的时间码复用现有播放器控制。陈旧来源禁用跳转/汇总，仍允许只读历史。旧库/旧选择的迟到响应丢弃。
- 字幕与分析采用同一侧栏位置且互斥；窄窗口上下排列、宽窗口并排，播放器启动失败时仍能读取分析。色彩/焦点沿用语义主题变量，保留全局减少动效规则，无装饰性动画。
