# 课程来源预检资源边界

2026-11-01。课程预检在读取明细之前，使用同一个来源事务统计系列、课次及进度行数，以及实际读取字段的 SQLite 字节长度；超过合计 10,000 行或 2 MiB 时明确拒绝，不截断内容。每表最多统计 10,001 行，版本表最多读取 2 行。限制用于当前整库预检的资源控制；后续若支持分页选批，应重新设计此边界。

2 MiB 是来源字段的资源上限，并非暂存大小保证；暂存仍有独立的 1 MiB 上限，部分小于 2 MiB 的来源仍可能无法暂存。此检查也不限制所有目标库关联数据，不能证明预检在任意异常数据库上都具有固定内存或时间上限。

合成测试覆盖超大中文内容、大量小记录、正常较大内容不截断、拒绝后源事务结束及目标库未写入。本次未读取真实用户数据库、未完成原生桌面验收、未合并 main。
