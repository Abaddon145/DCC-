# Windows 离线课程副本入口

从 main `54fbad2` 开始。Windows 新增单独的离线副本选择入口，使用系统文件选择器并要求用户确认映流已退出、所选文件为副本；合成入口仍需要原有标记。页面不传入源路径。非 Windows 的离线入口拒绝执行。

离线入口对数据库及成对 WAL/SHM 使用拒绝写入租约、目录事件监视、双读和文件状态复核，SQLite 只打开临时副本；继续要求 schema 8、完整性和外键检查。来源文件身份绑定到现有来源 profile，同一文件重新选择保留身份，独立文件不因内容相同而合并。预检批准及提交沿用现有任务队列、指纹检查和撤回机制。

Windows 合成测试覆盖无标记副本、合成门闩仍拒绝无标记源、活动 SQLite 写连接、错误 schema、来源变化、重选身份、预检、提交及撤回。经用户授权的无标记真实离线副本在隔离测试资料库完成一次课程预检、显式绑定、提交和撤回；测试前后三个副本文件哈希一致，未记录课程内容。原映流库未用于此测试。

后续使用独立测试媒体覆盖整个离线副本的课程清单，核对每门课程均计入提交或冲突，撤回后测试课程和系列清除、测试媒体保留，副本文件哈希不变。所有课程冲突均为来源没有进度且目标中没有课程；未知进度未被当作零。界面分别说明预检可能保留冲突及提交后目标课程未创建。Windows 另行验证离线入口拒绝硬链接和目录联接；这不替代受本机特权限制的符号链接测试。
