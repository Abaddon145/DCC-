# 合成快照校验的时限

2026-11-01。快照备份后的完整性、版本及外键检查使用同一时限。SQLite 指令进度回调在到期时中止校验；成功返回前移除临时回调并复核时限，返回的快照仍可供后续读取。

回归构造包含大量计算的 schema_version 视图，旧实现超过 100 毫秒后仍返回成功，修正后拒绝。正常表快照返回后等待原时限过去，再执行递归查询仍成功，证明临时中止回调没有泄漏。学习迁入专项 192 项通过，日志 `release-artifacts/yingliu-merge/snapshot-validation-deadline-learning.log`。

该路径仍仅编译进测试；此时限是 SQLite 指令执行层的取消检查，不是进程级硬时限或文件 I/O 的即时中断，也不构成真实来源读取已可开放的证明。
