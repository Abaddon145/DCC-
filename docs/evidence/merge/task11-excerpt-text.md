# Task11a：可信摘录文字草稿

基线 `0bfdd99`。新增 learning/excerpts.rs 与定向测试，在既有 learning/mod.rs 注册；复用 subtitles::verified_cues、TimeRange/LearningReference 与唯一笔记JSON模型，无依赖、schema或前端命令变更。

- 输入只有课程/字幕/段落ID、明确时间段、备注及可选截图时间，不接受客户端字幕正文或磁盘路径。所属课程、有效时长、重复或未知段、跨课程字幕、时间顺序/重叠/越界均校验。
- 从登记字幕原件重新核对SHA并解析，选择顺序回到原文顺序；完整多行原文保留，不信任缓存表被改写的文本。相邻/重叠段合并范围，真实间隙保留；客户端额外范围不得扩大或截断选中字幕。
- 最多256段/范围、备注20,000字节、选中文字1MiB；超限拒绝，不截断。生成正文前再限制4096处换行，防止短原文膨胀成大量编辑器节点；文字草稿保留，此限制不改变历史笔记或导入能力。
- 生成学习引用与纯text/hardBreak节点，HTML片段作为文字；与现有笔记保存、全文搜索和媒体反链兼容。真正媒体SHA必须由后续只读租约取得，本步只做内部文字草稿，不宣称已取帧、验证视频或保存摘录。
