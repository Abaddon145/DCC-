# 来源 SQLite 的本机身份登记

2026-10-30。新增 schema 38 身份绑定表及 Windows 内部登记函数。经调用方明确选择后，锁定父目录链与普通文件句柄，以卷序列号、文件索引和创建时间登记本机身份；profile 和绑定同事务创建。同一已登记文件重新选择可复用 profile，不同文件即使内容相同也不会按内容合并。记录不包含来源路径，不授予读权限，也没有 Tauri 命令或产品读取入口。

合成测试验证登记复用、不同文件隔离、文件句柄防替换、硬链接拒绝、登记失败不留孤立 profile、版本升级失败回滚以及备份恢复轮换 epoch。另以合成 SQLite/WAL 连接来源身份、选择会话和课程预检。未打开真实映流数据库或用户文件。

后端全量重跑 736 通过、2 忽略，日志 `release-artifacts/yingliu-merge/sqlite-identity-rust-full-retry.log`；其后修改的课程预检联测及 3 项身份测试单独通过，日志 `release-artifacts/yingliu-merge/sqlite-identity-integrated.log`。首次全量中草稿保存原子替换失败一次（734 通过、1 失败、2 忽略），该项单独复测和全量重跑通过，根因未确认。本轮没有改前端，也没有重跑前端测试或构建。

限制：Windows 文件标识与创建时间只提供本机文件身份线索，不保证跨设备稳定，也不能证明同一文件没有被原位替换内容或文件标识不会被复用。历史库中没有数据库身份的 profile 不自动关联；不得仅凭身份记录或备份恢复获得访问授权。受保护快照仍有未解决的竞争边界，真实来源选择、生产读取、提交前复核和桌面验收尚未完成。
