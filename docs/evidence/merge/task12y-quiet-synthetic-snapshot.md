# 无侧文件的合成课程快照

2026-11-01。合成快照路径新增对没有 WAL、SHM 和回滚日志的安静数据库的支持：固定目录和数据库句柄，禁止写入，检查数据库头和侧文件缺失，将数据复制到临时目录，再只对副本打开 SQLite 并沿用 schema 8、完整性和外键检查。支持已关闭的 WAL 模式和回滚日志模式；不创建或修改源文件及源侧文件。

合成测试验证课程预检能读到来源进度；复制期间禁止写入和重命名，活动写入句柄、单独存在或中途出现的侧文件、回滚日志以及零超时均被拒绝。学习迁入专项 171 项通过（新增回滚日志模式测试之前），日志 `release-artifacts/yingliu-merge/quiet-snapshot-learning.log`；随后两个安静快照专项通过，日志 `release-artifacts/yingliu-merge/quiet-snapshot-final.log`。本次未改产品前端，未重复全量后端回归。

缺失的侧文件名不能被文件句柄锁住；多次检查不能排除侧文件瞬时出现并消失等竞争。该路径仍仅编译进测试，不构成生产来源授权，也未开放实际课程预检或写入。未访问真实用户数据库、未完成桌面验收、未合并 main。

[SQLite 官方 WAL 文档](https://sqlite.org/wal.html)说明，WAL 是数据库持久状态的一部分，不能将数据库与 WAL 随意分离；只读打开 WAL 数据库也有侧文件存在、目录可写或 immutable 等条件。[WAL 格式文档](https://www.sqlite.org/walformat.html)描述了 SHM 上的写入、检查点和恢复锁。因此，单次观察不到侧文件不能作为完整授权快照的充分证明；此结论是对本实验边界的保守推断。
