# Task11c1a 摘录统一后台任务

日期：2026-10-26。基线6d54a0b。本端隔离实现和测试，前端按钮/Composer尚未接入。

## 实现

- TaskRequest增加CourseExcerpt的prepare/commit动作，使用现有排队、取消、TaskCenter和手动重试/重启中断机制；没有新增队列或付费调用。相同库中的相同活动请求复用任务ID。
- 准备输入仅课程UUID、选中字幕ID/时间段、备注和帧时间；纯预算/重复ID/时间结构先检查，原有prepare_text复用同一验证。准备结果只写previewId到tasks.json，完整正文和JPEG保存在原有摘录存储。提交结果使用持久receipt及targetAvailable。
- runner核对任务当前状态、库和冻结payload，停止查询直接读状态，不在媒体摘要每块循环克隆整条任务。共享should_stop保持其他任务原停止位语义；新is_active_task用于摘录同时判断已停止/中断状态。
- 准备停止只取消未被新发布操作认领的ready草稿，不删除用户对象。提交的最后检查覆盖图片已复制/SQL已完成但尚未commit的取消窗口，回滚和清理清单中的未登记新文件。
- 已经可靠提交后才到的停止请求保留completed与回执，并提示停止晚于保存；准备任务的原stopped语义保持。状态记录与目标数据库不是同一事务，失败恢复以目标库中的持久操作回执为准。
