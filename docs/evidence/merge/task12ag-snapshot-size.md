# 合成 SQLite 快照的页数限制

2026-11-01。测试专用的 SQLite 快照在备份前读取页数和页大小，并在每次分步备份后复核页数；按初始页大小计算超过 256 MiB 时丢弃快照，不截断课程内容。该上限是当前整库内存快照原型的保守限制；未来支持较大来源需要重新设计有界提取。

合成测试先复现超限仍被接受，修正后验证恰好达到限制时内容完整，超过限制时返回错误且来源内容不变。学习迁入专项在沙箱外 180 项通过，日志 `release-artifacts/yingliu-merge/snapshot-size-learning-elevated.log`。沙箱内首次运行 176 项通过、4 项在创建硬链接时返回 Windows 拒绝访问，日志 `release-artifacts/yingliu-merge/snapshot-size-learning.log`；定向失败复现记录为 `snapshot-size-red.log`。本次未重复完整后端或前端回归。

页数限制不是进程内存的硬上限：SQLite 在单次备份步骤中最多继续处理 64 页，另有缓存和校验开销。它也不限制此前的临时文件复制、WAL 大小或操作系统 I/O 时间；分步期间来源增长的检测未单独进行竞争测试。该模块只在测试编译，未开放真实来源读取，未访问真实用户数据库、未进行原生桌面验收、未合并 main。
