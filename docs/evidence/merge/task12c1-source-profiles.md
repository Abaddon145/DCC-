日期：2026-10-28；起点 `bfc70e5`。本阶段新增的来源记录仅是库内身份，不接收来源路径，不读取映流数据，也不构成访问授权。

- schema v31 仅保存由栈藏生成的来源 UUID、固定应用名、访问 epoch 和创建时间。相同素材库 UUID 的不同根目录以及切换素材库后，旧操作范围不能直接用于新位置；旧归档中的来源字符串保持不变，不自动转成新身份。

- 修复旧版迁移在每次打开时降低 schema 版本的问题，并以解除项目笔记关联后重开库的测试验证该关联不会重新出现。
