# 学习资料迁入：目录授权与入队会话保护

起点 `8103141`。现有迁入界面后端此前接受前端传入的任意目录，不能证明用户通过对话框选择。此阶段将系统目录对话框移至 Rust；只有当前运行会话中由该对话框选定的目录可供预检和准备。用户取消后清除当前选择。恢复后按原有 epoch 保护拒绝旧选择；切库后按库身份和会话 nonce 拒绝旧选择。

准备完成后，任务入队在素材库锁内再次核验原始库身份和会话 nonce，避免预检与入队之间 A→B→A 切库导致旧任务进入新会话。未通过对话框绑定的旧数据库登记不构成当前授权。目录句柄不长驻，读取时仍由原有句柄与身份检查保护。

合成临时目录测试覆盖无授权、选择、取消、库会话变化和旧会话入队拒绝；不涉及真实映流数据。独立只读复核了调用链和锁顺序。尚未完成完整 SQLite、课程进度、附件迁入，也未完成原生对话框的实际桌面验收。已有进行中的读取不因重新选择而即时停止；结果仍受库范围、来源身份和 epoch 复核。未执行真实用户数据迁移、安装、推送、合并或发布。
