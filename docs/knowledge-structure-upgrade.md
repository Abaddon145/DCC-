# 知识工作台：统一内容结构与拖拽（待 Windows 验收）

沿用 0.17.0 测试版本、`codex/v0.17-knowledge-workspace` 分支及草稿 PR #8；本轮按确认的 Q1–Q6 A 实施，不合并、不创建正式 Release。

## 交互

- 按住笔记卡片并移动，拖入任意笔记本；“全部笔记”取消分类。笔记本可拖动换父级、上下调整顺序，禁止自身/后代；折叠目标悬停约 600ms 展开，边缘滚动。移动完成提供撤销。采用指针事件，不关闭 Tauri 原生外部文件拖入。
- 打开的笔记标签排序也改用同一指针拖动逻辑，关闭按钮不会误触拖动。
- Ctrl+E 在当前知识库内直接切换编辑/阅读，无需先点模式。弹窗、右键菜单、输入法组合及重复按键不触发；切换前安全保存。
- 正文 / 大纲 / 导图是同一份结构化正文的三个视图。每个顶层富文本块均有节点，章节按标题层级组织；嵌套列表、图片、表格、代码、附件、引用和旧独立导图保留为完整内容块，不压成纯文本。
- 导图显示节点摘要，选择后在右侧编辑完整富文本。标题拖动移动整节，调整对应正文顺序和标题级别；最多六级，越界拒绝。普通内容可移到章节内部。删除分支确认显示内容块、文字及附件/引用数量；原附件仍按原笔记生命周期保留，可撤销。
- 添加章节 / 内容；教程学习、知识点拆解、报错排查、CG 制作流程、项目复盘五种模板，可在旧笔记末尾追加，绝不替换旧正文。旧嵌入独立导图不自动转换。
- 右键笔记或标签 → 笔记颜色，预设、自定义、恢复默认。仅导航列表与标签使用淡色背景和色条，不改正文。颜色保存在当前库，复制、笔记包、回收站、备份恢复均保留；改颜色不改变正文修订号。
- 旧独立导图 SVG/PNG 导出完整长节点文字，自动换行。整篇导图导出结构摘要；完整正文继续用 Markdown/HTML/PDF/笔记包。PNG 最长边沿用 1600px 限制，大图建议 SVG 放大阅读。

## 数据与验证

- schema v14 → v15 增加可空 `knowledge_notes.navigation_color`；幂等升级，旧历史与旧笔记包缺少颜色时使用默认值。
- 新增 `set_note_color`、`get_note_structure_svg`，继续校验当前素材库 ID；颜色限 `#RRGGBB`，导出仅读已保存笔记及匹配修订号，不接受任意 HTML 或路径读取。
- 新视图复用 Tiptap 文档、保存队列与撤销栈，以及已安装 MindElixir；没有新增依赖或第二份可独立漂移的正文。
- 回归覆盖：列表焦点下快捷键、指针拖动与撤销、大纲编辑到正文、模板追加、导航颜色、丰富内容保留、循环/六级拒绝、迁移/包复制/整库备份、长节点导出。

## 2026-10-01 知识库操作后卡死修复

- 用户反馈：启动恢复知识库后有正常画面，但点击模块或按钮卡死。Windows 事件日志存在 v0.17.0 `AppHangB1`；只读检查当前数据库 `quick_check=ok`，未清空配置、笔记或素材数据。
- 可重复的保存边界测试：保存过程中重新注册同一编辑器回调，实时 `Set` 迭代器会再次访问回调，无法结束。本测试在修复前失败，并用有界次数防止测试自身挂死；并非声称已通过原生窗口复现所有卡死原因。
- `flushKnowledgeEdits` 改为遍历调用开始时的回调快照；编辑器全局保存回调仅在保存函数变化时注册，不随父级标签页渲染反复移除/插入。保留保存失败阻止切库、备份和导航的原有数据保护。
- 增加真实 App＋StrictMode 的知识库启动恢复、阅读切换、返回素材库测试，以及正文/大纲/导图恢复与有界 IPC 测试。
- 自动化：前端 158 项通过，Rust 141 项通过、2 项默认跳过。用户仍需在新安装包上验证点击模块、保存/历史、切笔记、三视图和备份不会卡死；未正式发布或合并 PR。
