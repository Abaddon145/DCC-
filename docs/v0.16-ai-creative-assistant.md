# v0.16 AI 创作助手（测试版）

## 入口与工作方式

侧栏“创作”分组新增默认启用的“AI 创作助手”，可在模块中心隐藏和排序。素材详情、多选工具栏、媒体详情/多选、项目工作区、搜索框和命令面板提供入口。

1. **创作方案**：填写创作目标，可关联现有项目或在应用时新建项目。返回方向、步骤、素材需求与场景/镜头任务。任务逐项勾选，添加到“待办”；不会替换已有项目说明和任务。
2. **整理建议**：针对明确选中的普通素材、图片、模型、音频、视频提出名称、描述、追加标签和分类/文件夹建议。普通素材按所选中英语言处理，独立媒体仅中文。许可、作者、来源、格式、软件版本不在可写字段中。
3. **自然语言检索**：生成可检查的本地检索条件，再点击“运行本地搜索”。素材使用现有高级语法；媒体使用文字子串。结果只来自当前库，分页显示，不把模型生成的名称当作检索结果。
4. **项目选材**：选择目标项目，使用明确选择的条目，或输入简短本地召回关键词。AI 仅对有限候选给出用途及待核实信息；确认后素材以“候选”加入，媒体建立关联。已有关联和用途不覆盖。

## 隐私、用量与请求边界

- 准备草稿仅在本地执行。确认发送前显示文字上下文、候选数量和保守 Token 预留估算；API 计费以 DeepSeek 账单为准。
- 固定官方 HTTPS 端点和现有 `deepseek-flash` 模型；不接受任意 API URL，不运行模型输出的脚本、工具调用或命令。
- 只发送确认的文字要求、条目基本信息、项目资料、有限分类/标签词表。不读取或上传图片、模型、音视频内容，不发送网盘提取码或工程快捷路径。
- 每次最多明确选择 40 项；本地召回与明确选择合计最多 50 项；每类本地结果按 40 项分页。元数据描述最多提供 6000 字，整体请求文本有大小上限，超限要求缩小范围。不会静默截断用户明确选择的 ID。
- 分类、文件夹和标签词表各有最多 500 项的上下文边界；未发给 AI 的同路径分类仍在应用时由数据库复用。新建素材顶级分类受现有规范限制；回收站同名分类要求先手动恢复。
- AI 请求与翻译共享本机月度总限额，单独记录创作子计数。收到有效 usage 后按实际量结算；取消、超时、异常退出等结果不明请求保留预留。取消不能保证服务商不计费。
- 临时服务/网络错误最多重试一次；鉴权、参数、余额错误不自动重试。AI 创作不回退到百度翻译。达到本机上限不发送新请求。
- 默认快速模式；仅创作方案可选择“深入推敲”，预留更多输出。独立单请求执行通道，不排在媒体导入任务后面；数据库提交仍遵守库锁与维护状态。
- 成功且通过结构校验的结果可使用本机缓存；遵循现有缓存开关。重新准备相同请求可能复用结果。清空服务缓存不清除草稿、不重置用量。

## 审核、应用与撤销

- 生成内容始终是未应用草稿。返回的类型、数量、ID、用途和可写字段由 Rust 再次验证，未知 ID 或越权字段拒绝接受。
- 预览默认不勾选，逐项选择后再次确认应用。名称/描述可替换选定语言字段；标签只追加；分类与文件夹仅在确认时创建。
- 应用在单个 SQLite 事务中完成，包含必要分类、标签、项目/场景/镜头、任务、关联和搜索索引。任一项失败整批回滚。
- 应用前对比准备时的数据快照，防止覆盖预览期间发生的手动修改。
- 每库仅保存最近一次 AI 应用的撤销记录，可跨重启使用。撤销前对比应用后的关联数据；后续修改、新分类/标签被其他内容使用等冲突会拒绝撤销。查看历史时间不视为编辑冲突。
- 撤销不退款、不撤回已发送的在线请求。删除草稿不会删除已经应用的素材/项目数据。关闭模块不删除历史。

## 数据与兼容

数据库升级为 schema v13，新增 `ai_sessions` 与 `ai_last_undo`。迁移原子执行、可重复打开，旧字段不变。草稿、上下文、结果与撤销日志随数据库备份、恢复和迁移；库 UUID 校验阻止跨库应用。

DeepSeek 凭据仍只存 Windows 凭据管理器。全局月度计数与成功结果缓存位于 `translation-cache.sqlite`，不进入素材库备份。进程退出后未完成请求标为中断，不自动恢复联网。

## 验证与实机验收

本地前端 95 项、Rust 111 项测试通过，生产构建通过。新增覆盖发送确认、结果选择、无凭据、取消、草稿打开、搜索确认、越权结果、事务回滚、分类与标签、媒体整理、项目关联不覆盖、共享用量、服务错误重试、跨重启撤销、冲突拒绝和完整备份恢复。网络测试使用本机模拟响应，不调用真实服务或消耗额度。

仍需 Windows 实机验收：

1. 覆盖安装，检查旧库正常打开、AI 模块可隐藏/排序，确认素材/媒体/项目入口。
2. 配置自己的 DeepSeek Key，先用少量文字验证真实服务 JSON 响应与计费；确认不勾选不会写入。
3. 从 1–3 条素材开始验证分类、标签、中文与英文描述；应用后重启并撤销。
4. 生成方案、只选一个任务加入项目；推荐素材后检查既有用途保持不变。
5. 同时运行媒体导入和 AI 请求，测试取消、切换页面、断网以及退出后的中断提示。
6. 检查窄窗口、中文字体缩放和不同主题；确认现有模型材质预览与导出不受影响。
