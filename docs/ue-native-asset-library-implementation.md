# UE 原生资产库实施记录

确认日期：2026-10-06。Q1-Q15 均采用 A；用户已确认开始实施。

## 已确认的范围

- 以 UE5Box 的资产使用闭环为产品参考，独立实现；未确认 UE5Box 有可复用的官方开源代码。
- 新增 UE 资产库，保留普通素材、媒体库、创作项目和知识库。首批原生预览完善 StaticMesh、Texture、Material、MaterialInstance；其他类型明确显示未支持状态。
- 支持完整工程、保留目录结构的原生素材包。孤立文件不假定版本、类型或依赖完整。
- 默认引用，可备份收录；虚拟文件夹、标签、收藏和中文别名不修改工程目录、包名或文件。
- 在栈藏中查看 UE 生成的缩略图和信息；深度交互使用独立 UE 预览工程，不将 GLB 代理标成原生预览。
- 允许最小 Editor 辅助工具；引擎启动、工具安装、源工程配置变更与目标工程写入均显式确认。预览工程不是操作系统安全沙箱，仍需可信代码与插件。
- 按匹配引擎运行；向高版本导入须在副本验证，禁止降级和缺失依赖时强行导入。原生数据不会仅靠文件名或前端判断成功。
- 任务主动触发，进度可见、可取消、可重试。栈藏启动不自动启动 UE；失败不抹掉上次成功的索引与缩略图。
- 支持 UE 右键收录，以及定位文件、在 UE 中打开、确认依赖与冲突后导入目标工程。
- 与现有项目、笔记、参考板及 Fab 素材建立关联，不自动复制为普通素材或独立媒体记录。
- 引用备份包含索引和预览缓存，不包含外部原件；备份收录包含原件与依赖。导出前说明外部路径依赖，恢复后提供重新定位。
- GitHub 交付至 Abaddon145/DCC-，功能分支和 PR，中文 Windows 测试安装包。UE 实测通过前不合并、不发布正式 Release。

## 界面审计与方向

- 现有品牌：栈藏，深色 Graphite / UE Slate / Midnight；琥珀强调色；Segoe UI / Microsoft YaHei UI；现有 7 / 10 / 14px 圆角。
- 保留内容 / 创作 / 管理导航，现有模块开关、排序、返回前进、可调整上下文栏、虚拟列表、详情外部关闭和焦点恢复。
- 保留已有加载骨架、旧数据保留与重试。避免各功能实现独立的一套任务或反馈逻辑。
- 采用目录 / 资产 / 预览布局，小窗口收起目录或叠加详情，不让选项挤压预览。长名称、操作按钮及错误信息需可读。
- DESIGN_VARIANCE=3，MOTION_INTENSITY=3，VISUAL_DENSITY=7。保留现有 React / CSS / Lucide，不为样式新增组件库。
- design-taste-frontend 的营销页规则不套用到桌面资源工具；采用其审计、品牌、对比度、状态与性能原则。

## 本机原生验证记录

- 2026-10-06，UE 5.6.1 在工作区 `.tools/ue-native-smoke` 临时工程生成 StaticMesh、Texture2D、Material、MaterialInstanceConstant，并通过真实 Asset Registry 读取四条记录。命令退出 0；输出 `Saved/stack-probe.json`。未读取用户工程。
- 缩略图组件取自 Kura 固定提交 `f8f6d06bf2a626f94cb10b0104b71ce80c6c5458`，保留 MIT 许可，并接受 Registry 的真实对象路径。没有复制其整套 UI。
- 首次构建被本机默认启用的 ConnecterUEPlugin 规则阻止；只在临时 HostProject 显式禁用。第二次构建进入下一阶段，提示缺少 NetFxSDK。未修改引擎安装或用户工程配置。
- 官方 VS 安装器第一次退出 5007，日志明确未提升权限；第二次已提升权限，但不能匹配使用 `/` 的安装路径。使用 vswhere 返回的 Windows 原生路径后，.NET Framework 4.8 SDK 安装退出 0，注册表和 SDK 路径已核实。
- UE 构建在中文工作区路径产生编译路径乱码。使用独立英文临时目录后，插件 DLL 编译和原生模块版本清单生成均成功，BuildId 与本机 5.6 引擎一致。源文件仍保留在工作区。
- commandlet 缩略图接口返回 true，但四张输出实际全黑。真实图像校验已复现并拒绝此结果，不能把 PNG 存在当作渲染成功。
- 改用完整编辑器的 `-ExecutePythonScript` 离屏入口后，实际渲染出立方体、材质球和纹理；Texture2D 原始尺寸为 128，其余为 256。自动检查通过，四个源文件 SHA-256 前后一致。共享渲染函数拒绝 commandlet 入口，避免黑图伪成功。
- 原生资产编辑器验证：首次用未暴露给 Python 的 C++ 方法失败，立即退出时测试进程还触发 Slate 崩溃；改为最小 C++ 查询桥接并关闭编辑器后，四种编辑器均注册成功，进程退出 0。
- 原生迁移验证：只选模型与纹理，UE 自动迁移模型的材质实例和父材质，共四个包；第二次迁移跳过冲突，源文件校验值未变。独立目标工程实际加载四个包通过，进程退出 0。
- 验证期间 UE 自行执行公共 DDC 过期缓存清理；这是可重新生成的派生缓存，不是素材原件。未删除用户素材或工程。
- 验证范围是 UE 5.6.1 官方原生测试资产；5.7/5.8、真实用户工程、第三方插件和鼠标交互仍未验收，不据此宣称全面兼容。

## 最终实现与回归结果

- 数据库 schema 20；UE 来源、虚拟文件夹、原生索引和关联仅属于当前素材库。来源默认外部引用，不移动原工程 Content。准备工具的缓存路径使用短英文目录和源码校验值，避开 Windows 构建路径长度限制。
- 原生任务复用现有任务中心、独立数据库工作连接和已拥有进程的取消控制；不在执行 UE 时占用主窗口数据库锁，不自动启动引擎。素材库 UUID 在队列执行、收录和关联写入前重新校验。
- 原生读取仅使用数据库登记资产 UUID。索引解析失败、缺失依赖、来源失效不标记成功；索引事务回滚和失败缩略图保留上次成功缓存。
- 导入确认绑定来源校验值、目标工程配置和已有冲突文件校验值；发布使用不覆盖的原子文件写入，失败仅撤回此次新增且未被改动的文件。首版已有冲突一律跳过，不自动替换。
- 共享中文标签的使用计数、合并及清理覆盖普通素材、独立媒体和 UE 资产。项目、笔记、参考板和普通素材关联复用已有选择器，不增加组件库或拖拽依赖。
- UE 右键插件已真实编译；应用后端在临时工程完成安装并验证配置安全副本。右键收录请求限定授权工程、令牌、素材库 UUID、版本和 `/Game/` 对象路径；不发送令牌给前端。实际鼠标右键选择仍待人工验收。
- 应用后端真实端到端测试单独执行通过：准备辅助工具 → 登记 UE 5.6.1 工程 → 索引四类原生资产 → 渲染四张缩略图 → 仅选择模型与纹理、连同材质实例和父材质迁移四个包 → 在独立目标工程重新索引和渲染四类资产 → 安装右键入口并验证配置副本。最近一次运行 43.54 秒。
- 前端全量 224 项通过；Rust 全量 182 项通过、3 项默认忽略。被默认忽略的 UE 真机测试已另外显式运行通过；其余两项为大型生成数据基准和真实远程 Markdown 图片验收。CI 不启动 UE、不调用真实在线服务。
