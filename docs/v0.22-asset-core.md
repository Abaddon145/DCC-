# v0.22.0 Asset Core 2.0 — 资产核心体验版

当前交付为 Windows x64 测试版，需完成真实网站、Epic 和干净环境安装验收后才适合作为正式稳定版。未授权远程推送、合并或发布。

## 功能与使用

1. 打开素材库，默认仍是原“普通素材”布局。切换“全部资产”查看当前库的普通素材与四类媒体。两个范围的查询和选择互不混用，全部资产不显示 Fab 专属批量操作。
2. 在全部资产中按名称/标签、类型和来源筛选；每页 80 项，后端最大 200。卡片打开统一详情，可回到原素材或媒体详情继续原流程。
3. “扫描 / 导入文件”中选择外部目录。扫描只生成流式清单，不自动入库。预览可导入、重复、不支持及错误条目，确认所选行后才复制原件。
4. 本阶段目录扫描支持 PNG/JPEG/WebP、MP4/MOV/MKV/WebM、MP3/WAV/FLAC。GLB/GLTF/FBX/OBJ/STL 等继续走三维模型库；UE 格式只提示预留，不解析。
5. 相同 SHA-256 默认跳过，可打开现有资产。只有明确选择项目才建立项目使用引用；回收站重复需先恢复。不从文件名猜测标签或项目。
6. 详情中的标签沿用原中文/英文关系和中文媒体词库，颜色只接受 #RRGGBB。移除标签关系不删除其他资产使用的词。
7. 来源汇总原详情 source_url、下载 media_sources 及新增来源。旧来源只读，回原详情修改；新增来源可删除，拒绝可执行协议和带用户名/密码的 URL。
8. 创建 v001/v002/Final 等手动版本，引用当前库真实存在的已登记原件；追加原件复用现有安全媒体导入，再附加引用。版本不是自动版本控制，不复制第二份文件；删除版本不删文件。
9. “补齐元数据与缩略图”加入任务中心。原件缺失/处理失败明确显示；已有预览优先复用，3D 沿用原流程。图片/音视频/模型预览继续使用现有 UUID 协议与查看器。
10. 下载完成仍进入原音频/视频库，额外返回核心资产 ID；保存原件级时长、尺寸、编码、FPS，来源及字幕依赖可在统一详情查看。

## 数据库与兼容

schema 20→21，新增 asset_core、asset_files、asset_metadata、asset_sources、asset_versions。tags/localized_tags 仅增量增加颜色和创建时间字段。

assets/media_entries 仍是原基础信息的权威表，没有复制一份独立可编辑的名称、描述、分类或标签。即使两种旧记录恰好同 UUID，也各有独立稳定的核心身份；旧笔记引用和项目关联不变。

迁移登记旧文件引用，不移动、复制、全库哈希、ffprobe 或重建缩略图。软删除保留原文件与版本；永久删除先验证其他资产版本是否仍引用其原件。同批次删除双方允许清理，各方未确认的外部引用阻止清理。

备份容器格式不改，包含核心数据与 `.dcc/cache/thumbnails/<fileUUID>/` 限定缓存。排除 `.dcc/runtime` 扫描/下载临时目录、Cookie 与翻译密钥；旧备份恢复后自动增量迁移。

## 实现取舍

- 在用户批准的当前工作区分支实施，v0.21.1 未提交修复先单独保存，不重置、清理或远程发布。
- 保留旧表、旧 ID 和文件路径；新核心是引用层，不是第二套媒体库。
- 流式导入每次调用现有媒体导入器处理一个文件，复用现有事务与失败清理；代价是逐文件调用开销。
- 公共复制和哈希增加取消检查、无覆盖与复制后校验；代价是导入多一次完整性读取。
- 短视频封面改用第 0 帧，支持不足一秒视频；首帧淡入可能影响封面观感。
- 只清理本次生成且已被替换的 `.dcc` 缩略图缓存，不冒险删除旧处理器拥有的文件；旧缩略图可能需后续健康清理。
- 扫描增加一次流式清单核对及索引 Hash 查找，保证摘要/分页重复计数一致；超大目录存在逐行查询成本。
- 来源搜索通过已有 rusqlite 的确定性函数复用详情域名规则，不引入新依赖或 SQL 版 URL 解析器；每个检索连接需注册函数。
- 前端全套测试使用两个 jsdom worker；代价是运行时间约 35 秒而非资源竞争下的 16 秒。

## 安全与范围

新命令必传 expectedLibraryId；后台任务绑定创建时素材库；过期前端响应不污染新库。扫描拒绝链接/junction/reparse point、托管目录、`.git`/`.dcc` 和越界路径，导入前重新检查当前内容。

文件协议只使用已有登记 UUID，不把任意路径交给前端读取。临时复制和缩略图生成采用安全路径、原子提交和现有子进程控制。来源、预览及日志不增加凭据暴露。

没有新增自动语义标签、AI 分析、向量检索、Prompt 系统、视频剪辑、自动镜头识别、UE 完整资产浏览，也未恢复评分或树状合集。未修改 video_downloader。

- 干净 Windows 10/11 中文安装/升级/卸载和备份恢复；不卸载或覆盖用户正在用的版本作自动验收。
