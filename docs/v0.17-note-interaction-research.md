## 一手参考

- [Joplin 菜单位置 API](https://joplinapp.org/api/references/plugin_api/enums/menuitemlocation.html)区分笔记、文件夹、编辑器菜单，并传入右键目标。实现采用“操作右键目标”，而非隐式操作当前打开笔记。
- [Trilium 树菜单](https://docs.triliumnotes.org/user-guide/concepts/ui/note-tree/context-menu)展示创建、移动、复制和删除等树操作。Trilium 的 clone 不是独立副本，本应用不会采用多位置共享笔记概念。
- [Trilium 正文菜单](https://docs.triliumnotes.org/user-guide/concepts/ui/note-menu)按选区和编辑环境提供操作。本应用按选区、表格和只读状态调整菜单。
- [Obsidian 官方文档 GitHub](https://github.com/obsidianmd/obsidian-help)、[标题语法](https://obsidian.md/help/syntax)及[大纲](https://obsidian.md/help/plugins/outline)：以 Markdown 标题层级组织正文，用当前笔记标题列表导航。本应用保留 Tiptap，增加正文/H1/H2/H3选择、可折叠大纲；旧 H4–H6 内容保留，不自动编号或改写旧结构。

仅参考公开交互，未复制 Joplin/Trilium GPL/AGPL 代码。外部点击和 Esc 关闭历史面板是用户确认的本应用设计，不声称是上述产品的既定规范。

## 实现

- 历史：点击外部、再次点击按钮、Esc 关闭并退出历史预览，恢复当前草稿；异步历史读取失效保护，不自动恢复版本。
- 右键：笔记支持创建/重命名/移动/收藏/复制/笔记包导出/历史/删除；回收站支持恢复和二次确认永久删除。笔记本支持创建笔记/子级/重命名与移动/删除空节点。
- 正文：选区内右键保留选区，选区外定位；撤销、剪贴板、格式、列表、表格行列、附件与链接、AI 选区入口。AI 仍需预览发送内容；历史/回收站/维护屏障禁用修改。
- 复制：复用经过路径和摘要校验的笔记包管线，附件独立复制、自引用重映射，保持准确笔记本 UUID，不复制历史、收藏、学习日志日期。数据库事务失败不留下半成品。
- 删除：软删除并可撤销，副本附件不受原笔记永久清理影响。
- 菜单：顶层定位，复用已有菜单边缘算法；外部点击/Esc/选择动作关闭，不因鼠标移开关闭，支持方向键定位。
- 阅读：三级标题字号与间距、正文节奏、大纲跳转；复查现有素材/媒体/项目菜单的外部点击守卫，不改变此前用户约定的悬停规则。
