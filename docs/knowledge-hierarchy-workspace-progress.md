# 知识库多级主题与自适应工作台

本次依据已确认的 Q1–Q11 全部 A 实施。沿用 Tiptap、MindElixir、现有图片灯箱与导航拖拽，不引入新依赖；仅参考幕布/Xmind 的产品交互，不复制其他项目代码。

## 已实现

- 顶层富文本块按 `topicDepth` 保存真实父子关系，与 H1–H6 字体样式独立；`topicId` 保持拖动和格式调整后的主题身份。
- 旧笔记打开时在内存中按原标题关系转换，首次编辑后保存；不会自动重写已有历史版本。
- 普通主题中 Tab 新建子主题、Enter 新建同级、Shift+Tab 提升，Shift+Enter 由编辑器处理主题内换行。表格、代码、原生列表保留自身键位。
- 大纲选中主题后原位编辑完整富文本；导图选择主题后编辑完整内容面板，所有修改写回同一份正文，可撤销。
- 连续 Tab 不受标题六级限制；安全上限为 32 层，仍保留已有 4 MB 文档限制。后端验证越级、重复标识和不安全颜色后才保存。
- 导图提供中心双向、右向逻辑、向下树状，石墨/海蓝/森林主题及自定义分支颜色；布局和主题随笔记保存。
- 导图显示托管图片缩略图；点击复用现有图片灯箱，支持缩放、平移和图片切换。不会直接加载未托管的远程图片。
- 模式切换栏和保存栏不参与正文滚动；大纲/导图占用剩余空间，不再依赖固定屏幕高度；正文使用单个内容滚动区。
- 笔记本导航与笔记列表可分别折叠，保留现有外观设置中的宽度调整与专注模式；导图内容面板可折叠。
- 保留用户缩放/平移，提供适应全部、适应选中与 100%。大纲缩放不再放大顶部工具栏。
- Markdown 用嵌套列表保留主题层级与附件链接；HTML/PDF 保留层级缩进，结构化包继续保留完整文档。
- 普通素材卡片未增加手动排序效果，实际素材库数据未用于测试或修改。
