# 知识库快捷键与导航拖拽测试版

当前版本仍为 0.17.0；本次为已有知识库工作分支的增量测试，不合并 main、不创建正式 Release。

## 已接入

- 正文、大纲和整篇导图的格式快捷键；结构焦点下新建同级、缩进、提升。
- 当前笔记搜索与全库笔记搜索、缩放、Windows 区域截屏入口。
- 可修改的笔记快捷键，按笔记与应用上下文检查冲突。
- 分类、媒体文件夹、笔记本、笔记标签页、智能集合、模块设置、任务看板共用指针拖拽反馈。
- 导航拖起预览、等高占位、有效/无效落点、边缘连续滚动、取消清理。
- 笔记手动顺序按笔记本或全部笔记独立持久化；筛选后重排保留隐藏位置。
- 素材与媒体卡片保留拖入分类/文件夹，不添加卡片手动排序效果。

## 自动验证

- Vitest：44 文件、168 测试通过。
- Rust：142 测试通过，2 个既有性能测试忽略。
- TypeScript 与生产构建通过；构建仍提示既有大 bundle。
- 新增覆盖：占位与取消、任务跨列/分页位置、搜索跨文字标记、启动后直接打开搜索、格式安全归一化、筛选手动顺序。

## 发布前仍需确认

- Windows 原生鼠标体验、区域截屏与剪贴板实际行为、缩放后的落点、多显示器 DPI。
- 独立嵌入导图当前格式作用于整个选中主题，不是主题内部分文字。
- 独立导图截图入口截取后回正文粘贴，不在主题内直接嵌入图片。
- 离线导图 SVG/PNG 的格式表现，以及搜索从结果跳至具体正文位置仍需补齐。

上述未完成项不能视为已通过完整功能验收。
