## 能力边界

- 资产格式：未发现 FBX/OBJ/GLTF 等资产导入兼容表。文档 AI 模型生成章节宣称可导出 `.uasset`；不能据此推定所有原生资产都可解析或预览。[来源](https://ue5box.com/docs.html)
- `.umap`、`.uasset` 文件出现在协作界面的预告演示中。协作权限和版本回滚明确仍在开发，不能当成已发布能力。[来源](https://ue5box.com/)
- 知识库格式清单涵盖 PDF、文本、Markdown、MP3、DOCX、AVI 和多种图片；这是知识摄入格式，不能当作 3D 资产支持清单。[来源](https://ue5box.com/docs.html)
- 版本与依赖：文档建议 Windows 10/11 64 位、UE 5.0+、16GB 内存，UE4 仍待扩展；提到插件安装，但未给出插件名称、跨版本迁移矩阵或复杂依赖边界。[来源](https://ue5box.com/docs.html)
- 引擎需不需启动：资产沙盒没有技术说明；未知是否启动编辑器、临时工程、独立运行时或云端。知识库说明可添加已打开的 UE 工程，不能扩展推断为其他功能的运行条件。[来源](https://ue5box.com/)、[来源](https://ue5box.com/docs.html)
- 价格：页面显示月费 ¥29、年费 ¥276、创始会员 ¥1499、团队 ¥299/席/年且三席起。免费试用具体限制、商业使用权和离线授权规则未知。[来源](https://ue5box.com/)
- 开源许可证：官网与文档未发现官方 GitHub 链接或开源许可证；未知。没有将同名仓库认定为官方。文档的激活授权链接仅指向本页锚点，未提供独立授权说明。[官网](https://ue5box.com/)、[文档](https://ue5box.com/docs.html)
- 更新记录：首页下载标记为 0.1.19，文档注明最后更新 2025-01-09；未发现可核验的版本变更日志。官网演示 PPT 链接返回 404。[官网](https://ue5box.com/)、[文档](https://ue5box.com/docs.html)、[演示链接](https://ue5box.com/slides.html)

## 需要重开讨论的产品决策

以下是对栈藏的设计问题，不是 UE5Box 已证实的实现：

1. 首期对象是否包括完整 UE 工程和原生资产包，而不止交换格式模型？
2. 预览是否允许调用本机匹配版本 UE、创建隔离工程？不同选择决定保真度、性能和开发范围。
3. 引用库是否为默认模式；导入工程是否必须携带完整依赖、进行版本校验？
4. UE5Box 的广泛平台功能中，首期优先资产整理与预览，还是还要知识库、AI 和工作流？

页面描述与文档说明均未经实测。没有源码证据支持沙盒、依赖迁移、跨版本兼容或运行时实现的进一步结论。
