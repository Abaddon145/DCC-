# 知识工作台交互升级（测试版）

按确认的 Q1–Q9 A 方案实施，沿用 v0.17 草稿分支和 PR #8；Windows 验收前不合并、不发布正式 Release。

## 已接入

- 图片、附件和混合富文本选区的复制/剪切/粘贴；剪贴板写入失败不会删除原内容，同库跨笔记会复制附件所有权。
- 编辑/阅读视图，阅读时禁止内容修改；Ctrl+E 切换，Ctrl+S 提交。
- 多笔记标签页：切换、关闭、固定、拖动排序、重新打开和按素材库恢复；离开当前笔记前等待保存。
- 笔记拖入笔记本，笔记本同级排序、跨层移动和根级放置；循环拒绝、悬停展开和最近一次撤销，切库撤销失效。
- 独立嵌入式思维导图：可插入多个，可从标题初始化，节点编辑/移动/撤销/重做；不回写正文，按需加载 Mind Elixir 5.15.1（MIT）。
- Markdown＋附件和导图 SVG、离线 HTML（图片内嵌）、TXT、结构化 `.dccnotes`；导图独立 PNG/SVG 导出。
- PDF 走系统打印窗口“另存为 PDF”，使用静态独立文档而非应用侧栏/工具栏；不是无需交互的直接 PDF 写入。
- 专注模式和知识库外观草稿：预设、背景/正文/强调色、字号、行距、正文及面板宽度、代码主题；实时预览、取消恢复、对比度检查。

## 数据与安全

不变更数据库 schema；导图 JSON 随笔记正文进入现有自动保存、历史与整库备份，`.dccnotes` 保留可编辑结构。外观进入固定 app-settings，标签页进入当前库的工作区偏好。

富剪贴板只接受本进程缓存与 Windows 剪贴板序号一致的内容，不信任外部 HTML 标记；跨库不复制托管附件。导图限制 1000 节点、32 层，禁用远程图片/链接属性；预览栅格限制 1600px，避免超大 SVG 解码。

导出拒绝覆盖现有文件，HTML 使用转义文字、固定标签和禁止脚本/网络的 CSP。非图片附件在离线 HTML 中显示说明；完整附件迁移使用 Markdown＋附件或 `.dccnotes`。

## 验收

自动化已覆盖阅读锁定、标签去重/恢复、富剪贴板图片恢复、跨笔记附件所有权、目录循环/撤销、导图验证/转义/持久化和导出。

仍需 Windows 实机确认：原生剪贴板序号、系统 PDF 打印、导图键盘/拖动与 PNG、笔记拖动和 600ms 展开、重启恢复标签与滚动位置、保存失败拦截关闭，以及整体视觉布局。测试包不代表这些手动项已通过。
