# v0.18.0 稳定性与恢复测试版

## 已实现

- 素材附件导入与代理重试移到任务中心的独立 SQLite 工作连接，不再长时间占用主素材库锁；取消与失败结果可见。
- 损坏任务日志保留原文件并阻止新任务覆盖；记录写入失败时停止可取消任务。中断的在线任务不会自动执行。
- 旧回收站升级使用事务；备份期间禁止带文件清理副作用的参考板列表命令。
- 恢复备份之前写入持久中断标记；中断后启动暂停库内修改。在设置中心的数据页明确确认后恢复原库，不自动猜测恢复结果。
- 未保存笔记先写独立恢复副本，恢复为新笔记，不覆盖原笔记；检查或处理恢复副本之前不允许编辑。正文、附件仍使用原有笔记包恢复流程。
- 素材、媒体、知识库、项目、标签、回收站增加局部等待反馈和读取失败重试；分页失败停止自动请求，避免失败循环。媒体批量修改和回收站操作防止重复提交。
- 主界面与模块错误边界、系统减少动画偏好、手动脱敏诊断导出。诊断仅含固定事件码、时间、应用版本，不包含正文、文件路径、原始异常、凭据或签名。
- 离线学习复习：日期、待复习/已掌握、到期队列，使用素材库内的 `knowledge_reviews`；schema 17 自动升级。
- 项目交付清单：静帧、场景、动画模板，预览时可修改标题及选择条目，加入现有待办，同名任务跳过。
- 自动完整备份默认关闭：间隔 1–168 小时、保留 1–20 份、目标目录必须在当前素材库之外。只在应用运行、库有变化且任务空闲时启动；悬浮参考板时跳过。只轮换登记过的当前库自动备份，不删除手动备份。

## 安全边界与已知限制

- 恢复副本位于本机配置目录，不是整库备份的一部分；编辑后约 250ms 写入，保存前强制写入。进程突然终止仍可能丢失最后不足 250ms 的输入，不能承诺零损失。
- 若本机恢复记录或恢复原库副本损坏，停止处理并保留原文件；需要使用恢复前完整安全备份处理，不静默覆盖。
- 附件导入批次中断后不能安全区分“已提交但尚未记录”的最后一项，因此不重放整个批次。先在详情中检查，手动补导缺少的文件，避免重复附件。
- 自动备份使用数据库/WAL 文件变更检测，并非持续文件监视；应用关闭时不运行。改变备份目录不会删除旧目录的备份。
- 复习列表显示前 200 项；高级间隔重复算法、云端诊断上传、后台服务均未增加。
- 原有大前端 chunk 警告仍存在；本次未为消除警告而重写模块。
- Windows 原生窗口、低磁盘空间、真实断电和真实大媒体操作尚须手动验收。在线服务测试只使用本地模拟服务，不消耗额度。

## 验收清单

1. 创建笔记，强制退出后重新进入：出现恢复副本，可恢复成新笔记或明确丢弃；图片仍可显示。
2. 损坏任务日志后启动：任务中心出现警告，原日志不会被覆盖，付费任务不自动继续。
3. 导入视频/音频附件期间仍可操作导航；取消后已完成附件保留，不重复提交批次。
4. 恢复备份中断后进入设置中心数据页：只有确认才还原原库；复核素材、媒体、笔记附件和参考板。
5. 启用自动备份后，检查完整备份可恢复，且手动备份与其他素材库的文件不被轮换删除。
6. 断网时读取失败可重试，不显示空库误导；重复点击不重复执行破坏性操作。
7. 开启减少动画偏好，检查等待状态依然可理解；运行 Windows 10/11、窗口缩放和悬浮参考板回归。
8. 复习日期/掌握状态重开后保留；项目清单修改后加入并跳过同名任务。

测试通过后交付草稿 PR 和中文 x64 NSIS 测试安装包；用户验收前不合并、不创建正式 Release。
