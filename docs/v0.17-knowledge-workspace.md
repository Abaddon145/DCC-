# v0.17 知识库工作台（实施中，尚未发布）

分支：`codex/v0.17-knowledge-workspace`。基线为 v0.16；完整验收前不升级发布版本、不生成正式安装包、不合并 PR。

阶段验证（2026-09-30）：前端 104 项测试、Rust 122 项测试通过，前端生产构建通过。尚未执行 Windows 新功能手动验收；主包仍有既有的体积警告。此记录不是完整 v0.17 验收结论。

## 已落地

- schema v14：笔记本、结构化笔记、全文索引、历史版本、附件、引用。
- 每次写入同时校验素材库 UUID 和笔记 revision。事务更新正文、引用与 FTS。
- 中文短查询使用转义 LIKE，长查询使用 FTS5 trigram。列表分页返回 240 字摘要，不返回完整文档。
- 默认启用知识库模块；Tiptap 编辑器按路由延迟加载。空白及五种学习模板、每日学习日志、笔记本树、收藏、搜索、笔记回收站。
- 自动保存队列串行提交；后返回的旧响应不会覆盖新输入；失败保留队列草稿并提供重试。
- 切页前保存，切库/备份/恢复期间暂停编辑；主窗口关闭先请求编辑器保存。
- 最近 50 个未固定历史版本，固定版本不自动清理；一分钟内合并自动保存历史。恢复前预览，并在同一事务中保留恢复前版本。
- 图片与 PDF/文本附件复制到托管目录，按 UUID 读取；拒绝目录穿越、远程图片与非 HTTP(S) 文本链接。附件进入整库备份、恢复和目录迁移。
- 素材、独立媒体、项目和笔记引用卡片；笔记反向链接。引用没有针对来源实体的级联外键。
- 软删除保留附件，明确永久删除才清理；正常笔记不可直接永久删除。
- 素材全局搜索增加知识库结果入口。
- DeepSeek 笔记整理、摘要、复习问题与基于本地检索的问答；用户预览并确认精确发送的文字，模型回复只作为预览。复用共享请求通道与月度预算，引用 ID 必须来自所选笔记。

## 产品参考与许可边界

- [Trilium](https://github.com/TriliumNext/Trilium)：层级、富文本、版本、离线检索。
- [Joplin](https://github.com/laurent22/joplin)：本地笔记、附件与 Markdown 可迁移性。
- [Logseq](https://github.com/logseq/docs/blob/master/db-version.md)：反向链接、日记；不采用其块数据库。
- [Tiptap MIT 开源编辑器](https://github.com/ueberdosis/tiptap/blob/main/LICENSE.md)：使用开放编辑扩展，自行实现持久化、历史与 AI。

仅借鉴前三者产品思路，没有复制 GPL/AGPL 实现；不使用 Tiptap 付费协作、AI 或历史服务。
