# v0.17 知识库工作台（测试交付，尚未正式发布）

分支：`codex/v0.17-knowledge-workspace`。基线为 v0.16；测试版本号为 0.17.0。Windows 验收前不合并 PR、不创建正式 Release。

自动验证（2026-09-30）：前端 113 项测试、Rust 131 项测试通过；另有 1 项默认忽略的大数据基准已单独执行通过。生产构建与中文 Windows x64 NSIS 测试打包通过。尚未执行 Windows 新功能手动验收；主包仍有既有的体积警告。此记录不是完整用户验收结论。

## 已落地

- schema v14：笔记本、结构化笔记、全文索引、历史版本、附件、引用。
- 每次写入同时校验素材库 UUID 和笔记 revision。事务更新正文、引用与 FTS。
- 中文短查询使用转义 LIKE，长查询使用 FTS5 trigram。列表分页返回 240 字摘要，不返回完整文档。
- 默认启用知识库模块；Tiptap 编辑器按路由延迟加载。空白及五种学习模板、每日学习日志、笔记本树、收藏、搜索、笔记回收站。
- 自动保存队列串行提交；后返回的旧响应不会覆盖新输入；失败保留队列草稿并提供重试。
- 切页前保存，切库/备份/恢复期间暂停编辑；主窗口关闭先请求编辑器保存。
- 最近 50 个未固定历史版本，固定版本不自动清理；一分钟内合并自动保存历史。恢复前预览，并在同一事务中保留恢复前版本。
- 图片与 PDF/文本附件复制到托管目录，按 UUID 读取；拒绝目录穿越、远程图片与非 HTTP(S) 文本链接。附件进入整库备份、恢复和目录迁移。
- 素材、独立媒体、项目和笔记引用卡片；笔记反向链接。引用没有针对来源实体的级联外键。
- 软删除保留附件，明确永久删除才清理；正常笔记不可直接永久删除。
- 素材全局搜索增加知识库结果入口。
- DeepSeek 笔记整理、摘要、复习问题与基于本地检索的问答；用户预览并确认精确发送的文字，模型回复只作为预览。复用共享请求通道与月度预算，引用 ID 必须来自所选笔记。

## 本次补齐

- Markdown＋本地附件导入导出；`.dccnotes` 无损保存当前结构化正文及引用附件，校验清单并重映射内部 ID。完整历史通过整库备份迁移。
- 剪贴板截图安全编码和托管导入；保存屏障等待已开始的图片导入，避免备份遗漏最新插图。
- 笔记本重命名、移动、创建子级和删除空节点；统一回收站展示笔记恢复及永久删除。
- 来源素材、媒体和项目预览与导航；失效来源保留可读引用。
- 历史摘要分页，点击后读取单个版本正文；反向链接只传摘要。
- 项目素材分页 60 项、任务分列分页 40 项；跨页多选与任务全列排序；用途/备注改为长文本对话框。
- 保存冲突时可另存草稿包，再明确重新读取库中版本；草稿不覆盖数据库中的新版本。
- AI 本地模拟服务验证精确发送、共享额度、引用校验及来源变更拒绝；测试不调用真实付费接口。
- 整库备份恢复验证笔记、托管附件和固定历史版本；文本凭据扫描未发现疑似密钥。

## 性能记录与待验收

临时库生成数据的后端测量：20,000 条笔记查询“材质”首屏 28.82ms、“Unreal”118.91ms、单条精确查询 12.49ms；5,000 项项目素材与 1,000 个任务的限量工作区读取 18.58ms。这些是测试机后端时间，不代表端到端界面延迟。

Windows 待手动验证：中文输入、快捷键、截图粘贴、关闭/切库保存失败、文件对话框、附件系统打开、长文视觉布局、安装升级及真实大库使用体验。AI 网络/额度和界面异常仍需真实环境验收。测试安装包不替代数据备份。
