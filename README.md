# 栈藏 · DCC 素材库

面向 Unreal Engine 与其他 DCC 资产的本地 Windows 素材管理器。素材文件保存在百度网盘，应用负责预览、分类、检索、收藏和分享链接管理。

## v0.8 功能

- 百度网盘链接改为可选；无链接素材可以正常保存、检索和管理。
- 当前搜索和筛选结果可一键全选，支持批量整理、拖拽、加入参考板和网盘保存助手。
- 持久回收站支持素材与完整分类子树的恢复、永久删除和手动清空。
- Fab 批量导入提供 `.xlsx` Excel 模板，简化为 `fab_url`、`baidu_url`、`ue_versions` 三列，逐项读取元数据和公开预览图。
- 编辑器支持 `Ctrl+S` 保存，素材库支持 `Delete` 删除与即时撤销，快捷键均可配置。
- 描述中的 HTTP/HTTPS 地址可安全打开；详情菜单使用顶层浮层，不再被面板裁切。
- 悬浮参考板支持 `Alt + 左键` 从空白画布拖动系统窗口。
- SQLite schema v7；旧版多列 CSV/XLSX 模板仍可导入。

- 分栏式设置中心：外观、素材视图、功能模块、快捷键、启动行为、在线服务和数据管理。
- Graphite、UE Slate、Midnight 三套深色主题，自定义强调色、紧凑密度、减少动画及面板宽度。
- 内置模块中心可按素材库启用、关闭和拖拽排序；关闭模块不会删除数据。
- 网格小/中/大卡片与虚拟化紧凑列表，共用多选、拖拽分类、收藏和详情操作。
- 智能集合可保存当前搜索和筛选，支持更新、复制、排序与失效条件提示。
- 中文/English 标签管理，支持搜索、重命名、同语言合并、删除关联和清理未使用标签。
- `Ctrl+P` 命令面板和可修改快捷键，带重复冲突检查和默认值恢复。
- 全局主题与快捷键跨库共享；模块、视图、启动和搜索偏好随素材库独立保存。

- 全屏多图灯箱，支持缩放、平移、快捷键和相邻图片预加载。
- 可创建、迁移和切换多个本地素材库；迁移后保留旧库副本。
- 百度网盘分享文本快速解析，自动识别链接与提取码。
- Fab 商品网址自动录入，补全基本信息、UE 版本并缓存全部公开预览图。
- 多选批量分类、标签和收藏，以及本地素材库健康检查。
- 素材名称、描述、标签和许可支持中文/English 双版本，搜索同时覆盖两种语言。
- 百度翻译在线互译，译文保存前可逐字段预览；Fab 导入可自动补齐中文。
- 翻译密钥保存在 Windows 凭据管理器，不进入素材库、备份或日志。
- 可手动检查全库百度网盘分享是否仍然存在；明确失效的链接会在卡片、详情和检查页中单独标记。
- 链接检查采用限速、一次重试和保守三态判定，验证码、限流或模糊页面不会误判为失效。
- 素材卡片可直接拖入分类；多选素材可一次移动，并支持拖到“全部素材”清空分类。
- 分类可拖入其他分类或调整同级顺序，悬停时自动展开，并提供最近一次拖拽撤销。
- PureRef 风格参考板，支持多个命名画布、素材预览图/本地图片/剪贴板截图独立快照。
- 无限画布支持框选、多选移动、等比缩放、旋转与 15° 吸附、层级调整、自动排列和 50 步撤销/重做。
- 参考板可分离为无边框始终置顶窗口，支持收回主窗口、隐藏工具栏和 PNG 导出。
- 参考板图片使用缩略图按需加载和视口裁剪；备份、恢复及素材库迁移会包含全部参考板快照。
- SQLite schema v6，旧素材库和旧备份打开后自动迁移。

## 开发

需要 Node.js、Rust stable、Microsoft C++ Build Tools 和 WebView2。

```powershell
npm install
npm run tauri dev
```

前端测试与构建：

```powershell
npm test
npm run build
```

生成中文 NSIS 安装包：

```powershell
npm run tauri build -- --bundles nsis
```

应用设置固定保存在 `%LOCALAPPDATA%\DCCAssetLibrary\app-settings.json`。默认素材库位于同一目录，也可在“数据与素材库”中迁移到其他位置。百度翻译 APP ID 与密钥由用户提供，并独立保存在 Windows 凭据管理器。卸载应用不会主动删除任何素材库数据。
