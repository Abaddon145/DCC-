# 栈藏 · DCC 素材库

面向 Unreal Engine 与其他 DCC 资产的本地 Windows 素材管理器。素材文件保存在百度网盘，应用负责预览、分类、检索、收藏和分享链接管理。

## v0.21.0 Phase 1：下载中心

- 新增链接解析、格式/清晰度选择、视频与音频下载、字幕随附和播放列表条目选择；下载进入现有任务中心，支持暂停、恢复、取消及失败重试。
- 文件经 ffprobe 校验后自动收录到现有视频库或音频库，保留作者、来源、缩略图和托管字幕。设置中统一管理另存目录、并发、代理、质量与安全 Cookie。
- 仅迁入映流的下载核心能力，原仓库不改动；没有新增剪辑、压缩、字幕编辑或 AI 分析。交付、验证范围和实机核对见 [Phase 1 说明](docs/v0.21-downloader-phase1.md)。
- 本次安装包名称包含“下载中心 Phase1”，不同于历史上已取消的同版本 UE 原生素材测试包；继续基于 v0.20.6 的现有功能开发。

## 翻译与 Fab 工作流

### 分段补译与安全回退

- 修复描述译文条数不符时误停整个服务、导致后续标签也失败的问题。格式异常会有限次数缩小分段，仍失败时按已有设置使用备用服务；不猜测错位译文、不缓存无效响应。
- 术语之间的标点、数字和空白原样保留，不发给翻译服务。每次补译修复仍检查共享月度额度，保留原文、已有译文与成功缓存；错误显示实际段数或空译文位置。验证与安装核对见 [v0.20.5 说明](docs/v0.20.5-deepseek-translation-recovery.md)。

### 双语补齐、统一分类与直接定位

- 单条与批量导入显示并保存同一个 Fab 自动补译开关。新建或主动重新读取 Fab 后保存，只补缺失中英字段；翻译失败仍保存原文和成功字段，结果留在任务中心，支持手动重试。
- 单条和批量采用同一 Fab 官方分类映射与保存事务；未分类条目复用或创建对应分类，保留用户手选分类。
- 正常定位直接打开所选商品；“定位无响应？恢复定位”才通过 UE 库重新交接。详情增加无需选择工程和版本的快速入口，保留工程兼容性检查。只报告请求已发送，仍需在 Epic 核对商品。
- 保存结果持续可见；关闭未保存编辑需确认，导入处理中锁定文件与映射，完整逐行结果可分页查看。测试与安装验收见 [v0.20.4 说明](docs/v0.20.4-fab-bilingual-category.md)。

- v0.20.2 修正旧 Epic 商品路由退回库首页的问题，改为 Fab 商品定位请求；不再把系统接受请求当成商品已打开。支持手动重试、复制英文商品名与打开官方商品页，不自动跳转浏览器。实机验收边界见 [v0.20.2 说明](docs/v0.20.2-epic-fab-routing.md)。
- 新建素材保存时自动补齐缺失中英内容；有效 Fab 来源采用官方分类，保留手填译文和分类。失败会保存可用原文并报告待补译，不伪装为双语完成。
- 兼容已取消的 v0.21 UE 任务历史：仅保留记录、不可执行，避免它阻断“补齐双语”等现有任务；不会重新启用 UE 原生素材模块。
- Fab 素材详情提供“通过 Epic 添加到 UE 工程”，选择已登记或本地 `.uproject`，核对真实工程版本与 Fab 官方支持版本，再打开 Epic 商品流程。工程和版本需在 Epic 中再次选择，不自动下载、不读取账号凭据。
- 基于原 v0.20 分支，保留原安装包和历史数据。测试边界与手动验收见 [v0.20.1 交付说明](docs/v0.20.1-single-import-epic.md)。验收前保持草稿 PR，不合并或正式发布。

## 知识库工作台

- 当前素材库独立保存笔记本、富文本笔记、标签、收藏、每日学习日志和五种学习模板；支持表格、代码、待办清单和 Markdown 快捷输入。
- 串行自动保存、失败重试、版本冲突保护；保留最近 50 个未固定历史版本，固定版本长期保留，恢复前可预览。
- 图片、剪贴板截图、PDF 和文本附件托管保存；笔记可关联素材、媒体、项目和其他笔记，并显示反向链接和失效来源。
- 素材全局搜索可直接找到笔记；统一回收站中可查看、恢复和永久删除笔记。
- 支持 Markdown＋附件，以及 `.dccnotes` 当前版本结构化笔记包的导入导出。完整历史版本随素材库备份、恢复和迁移。
- DeepSeek 按用户确认的选区或笔记整理、总结、生成复习问题及有来源的知识问答；回复先预览，手动追加，与翻译及创作助手共享月度额度。
- 项目素材每页 60 项，任务看板每列每页 40 项，跨页选择保留；用途与备注使用支持长文本和失败重试的应用内编辑框。
- 测试与 Windows 验收范围见 [v0.17 交付说明](docs/v0.17-knowledge-workspace.md)。Windows 验收前保持草稿 PR，不合并、不创建正式 Release。
- 本轮知识工作台：笔记及笔记本使用指针拖动；Ctrl+E 无需先点击编辑区域。正文、大纲和整篇导图共用富文本正文，支持章节移动、内容编辑、删除确认与撤销、追加五种导图模板。
- 笔记右键可设导航颜色，只影响列表与标签；独立旧导图保留。SVG/PNG 长节点文字换行不截断，schema v15 自动补充笔记颜色。验收见 [本轮交付说明](docs/knowledge-structure-upgrade.md)。

## 模型文件与备用翻译

- 三维模型详情和卡片右键菜单提供“在资源管理器中显示”，选中素材库托管的原件；“导出模型包”将模型与已托管的贴图、缓冲区、MTL 等依赖复制到新的工作目录。
- DeepSeek 在线翻译默认优先，百度作为备用；可调整顺序。额度不足、限流和临时服务错误可自动切换；鉴权或参数错误会暂停并提示修正。
- 手动翻译、Fab 填充和 Excel/CSV 导入共用专业术语保护与全局本地缓存，只补齐缺失内容；已有译文仍需在编辑器明确选择覆盖。
- 本机 DeepSeek 月度上限默认为 100 万 Token，可调整。调用前预留额度，收到响应后用实际 Token 结算；未知结果的请求保留预留值，防止超额重试。该计数不是服务商账户余额。
- 设置中心 → 在线服务填写自己的 DeepSeek API Key，点击“保存并测试 DeepSeek”。API 需要独立账户额度，测试连接也会产生少量用量。
- 缓存与本机用量位于全局 `translation-cache.sqlite`，不进入素材库备份；两家服务的凭据均只存 Windows 凭据管理器。

验证范围和实机验收说明见 [v0.15 交付说明](docs/v0.15-model-access-translation.md)。

### 媒体导入可靠性

- 修复后台媒体导入创建独立连接时错误执行带结果行的超时配置，导致所有类型导入报 “Execute returned results” 的问题。
- 使用专用 busy_timeout 接口，保留外键约束与 5 秒等待；不修改已有素材、媒体或图片。
- 补齐真实后台连接到模型/图片导入与保存的回归测试。已有失败任务可在任务中心手动重试。

## 工作流与任务中心

- 防止较早的详情响应覆盖新选择，点击空白关闭后不会被迟到响应重新打开；素材删除快捷键不会误伤媒体或项目。
- 跨筛选保留明确选择，显示当前条件与隐藏数量，完整清单按 100 项分页；切换模块/素材库清空多选。
- 各素材库独立记忆模块搜索、媒体文件夹、网格/列表模式、项目/页签和浏览位置；设置中可关闭记忆。模块导航支持后退/前进，不保存编辑草稿或选择。
- 媒体可批量加入项目，图片可复制到参考板，项目内可解除媒体关联而不删除原件。
- 任务中心管理媒体/Fab 导入、双语补译、链接检查、模型缩略图和数据维护；结果分页，取消在安全步骤生效。FFmpeg 超时/停止会回收子进程，媒体处理使用独立数据库连接。
- 上次中断任务保留记录，重新启动不自动继续联网/翻译。手动继续会再次询问在线额度；导入重试跳过已成功或重复的媒体。
- 数据维护不允许切库或写入；备份期间可检索与查看，恢复/迁移期间保留当前画面但暂停新的库读取。关闭程序会要求先安全停止任务或等待维护完成。
- 备份/迁移同时包含图片、参考板、独立媒体库及普通素材附件。SHA-256 使用流式读取；恢复预先验证并建立安全副本，再切换数据库与托管文件目录。
- 任务日志属于本机全局设置，不进入素材库备份；翻译凭据仍只使用 Windows 凭据管理器。

这是待 Windows 实机验收的测试版，不代表模型材质、超大文件和干净环境安装已全部验证。验收清单见 [v0.14 工作记录](docs/v0.14-workflow-upgrade.md)。Windows 验收通过之前，不合并 PR、不创建正式 Release。

## 模型纹理与预览

- 修复 GLB 内嵌纹理被内容安全策略拦截，导致模型发白及缩略图生成失败的问题。
- 模型视口操作栏移到画布下方，窄面板中自动换行，不再遮住模型；纹理失败提示使用可读名称。

### 模型封面与材质

- 三维模型库自动为新导入模型生成带材质的缩略图；打开模型库时按顺序补齐旧模型封面，失败会显示原因。
- 3D 预览加载 OBJ 的 MTL 和相对纹理，GLB/GLTF 的 PBR 材质使用中性工作室环境光；缺失贴图时保留几何体并提示。
- 可在模型视口调整角度后“设为封面”，或恢复整体视角重新生成自动封面；封面以托管 WebP 保存，原模型不变。

## 独立媒体库

- 新增图片库、三维模型库、音频库和视频库四个独立模块，四类入口共用统一的 MediaLibrary 实现。
- 媒体条目独立于普通素材，支持各自的树状文件夹、共享中文标签、收藏、搜索、多选整理和软删除。
- 导入媒体会复制原件并使用 SHA-256 跳过完全相同文件；音视频继续生成代理、封面帧或波形。
- GLTF 与 OBJ 会安全收集本地相对依赖，拒绝远程地址、绝对路径和目录穿越；五种模型格式均可进入 Three.js 交互预览。
- 普通素材预览可按需“收录到媒体库”，不会自动复制旧附件。媒体文件随备份、迁移和切库移动。
- 已取消树状手动合集和 0–5 星评分界面、筛选、排序及搜索语法；历史表和评分值保留以支持可逆升级。SQLite schema 升级至 v11。

## 素材预览附件与历史兼容

- 图片、视频、音频和 3D 模型统一作为素材预览附件管理，支持排序、封面、失败重试和回收站安全保留。

- 统一媒体查看器支持图片大图、视频/音频播放与 Three.js 3D 旋转、平移、缩放、网格及线框视图。

- 高级搜索支持 AND、OR、排除、完整短语和字段限定，并在名称中显示命中高亮。SQLite schema 升级至 v10。

- 项目素材篮可从素材详情或全结果多选直接加入，记录候选、选用、使用和不采用状态，并关联场景、镜头、用途与备注。
- 场景/镜头两级制作结构与四列任务看板，支持任务优先级、截止日期、素材关联、拖拽换列和实时进度。
- 每个项目可关联一个主参考板和多个附加参考板，并将项目素材封面批量加入主参考板。
- 项目根目录、主工程、输出目录和自定义路径可作为安全快捷方式；仅允许常见 CG 工程格式，不执行脚本或启动参数。
- 项目归档后才能永久删除；删除项目不会删除素材、预览图或参考板。SQLite schema 升级至 v9。

## Fab 分类与重复检测

- 单条 Fab 录入与 Excel/CSV Fab 批量导入会根据 Fab 官方分类路径自动归类，缺少的分类在保存事务中创建。
- 使用固定中文顶级分类和最多两层的规范结构；未知类型统一进入“其他 / 待整理”，不使用翻译或 AI 猜测分类。
- 按 Fab 商品 UUID 识别重复链接，忽略协议、`www`、页面语言、查询参数、片段和尾部斜杠差异。
- 重复检查覆盖当前素材库、回收站、同一导入文件和导入过程中的前序行；默认跳过并报告，不覆盖原素材。
- 素材库检查新增“重复 Fab 素材”，SQLite schema 升级至 v8 并自动回填历史 Fab 链接。

## 专业术语保护

- 术语、URL、路径、格式、版本号和代码标识符不再作为占位符发送给百度翻译；仅翻译它们之间的普通文本，再在本地安全重组。
- 修复长描述包含大量术语时，百度偶发吞掉单个占位符而导致整段退回英文的问题。

### 旧占位符兼容（历史）

- 修复百度翻译会改写术语占位符，导致整段译文安全回退为英文原文的问题。
- 占位符改为无自然语言含义的短编码，并兼容翻译服务插入空格、下划线或连字符。

### 术语管理

- 百度翻译增加 UE、Fab 与常用 DCC 专业术语保护，强制使用稳定译名并保留品牌、产品名、版本、路径、格式和代码标识符。
- 设置中心新增全局专业术语库，支持内置词启停、自定义覆盖，以及 Excel 导入导出。
- 手动翻译预览会显示术语命中与校正结果；Fab 单条录入和批量导入使用同一套术语规则。
- 已移除网盘保存助手；单个素材的链接打开、提取码复制和链接有效性检查保持不变。

## 素材管理与参考板

- 编辑器支持 `Ctrl+S` 保存，素材库支持 `Delete` 删除与即时撤销，快捷键均可配置。

- SQLite schema v7；旧版多列 CSV/XLSX 模板仍可导入。

- 分栏式设置中心：外观、素材视图、功能模块、快捷键、启动行为、在线服务和数据管理。
- Graphite、UE Slate、Midnight 三套深色主题，自定义强调色、紧凑密度、减少动画及面板宽度。
- 内置模块中心可按素材库启用、关闭和拖拽排序；关闭模块不会删除数据。
- 网格小/中/大卡片与虚拟化紧凑列表，共用多选、拖拽分类、收藏和详情操作。
- 智能集合可保存当前搜索和筛选，支持更新、复制、排序与失效条件提示。
- 中文/English 标签管理，支持搜索、重命名、同语言合并、删除关联和清理未使用标签。
- `Ctrl+P` 命令面板和可修改快捷键，带重复冲突检查和默认值恢复。
- 全局主题与快捷键跨库共享；模块、视图、启动和搜索偏好随素材库独立保存。

- 全屏多图灯箱，支持缩放、平移、快捷键和相邻图片预加载。
- 可创建、迁移和切换多个本地素材库；迁移后保留旧库副本。
- 百度网盘分享文本快速解析，自动识别链接与提取码。
- Fab 商品网址自动录入，补全基本信息、UE 版本并缓存全部公开预览图。
- 多选批量分类、标签和收藏，以及本地素材库健康检查。
- 素材名称、描述、标签和许可支持中文/English 双版本，搜索同时覆盖两种语言。

- SQLite schema v6，旧素材库和旧备份打开后自动迁移。

## 开发

需要 Node.js、Rust stable、Microsoft C++ Build Tools 和 WebView2。

```powershell
npm install
npm run tauri dev
```

前端测试与构建：

```powershell
npm test
npm run build
```

生成中文 NSIS 安装包：

```powershell
npm run tauri build -- --bundles nsis
```

应用设置固定保存在 `%LOCALAPPDATA%\DCCAssetLibrary\app-settings.json`，全局专业术语覆盖保存在同目录的 `translation-glossary.json`。默认素材库位于同一目录，也可在“数据与素材库”中迁移到其他位置。百度翻译 APP ID 与密钥由用户提供，并独立保存在 Windows 凭据管理器。卸载应用不会主动删除任何素材库数据。
