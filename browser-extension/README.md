# 栈藏网页采集扩展（Edge / Chrome，本地测试版）

## 安装

1. 先安装配套的栈藏 **v0.19.0**，建议升级前导出整库备份。
2. 将扩展 ZIP 解压到固定目录，不要删除或移动这个目录。
3. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。开启“开发人员模式”，选择“加载解压缩的扩展”，选中包含 `manifest.json` 的目录。
4. 在扩展页面复制 32 位 ID，打开栈藏 → 内容 → **采集收件箱** → **连接 Edge / Chrome 浏览器扩展**，粘贴 ID 并连接。
5. 回到网页打开扩展面板，确认目标素材库。首次使用或切换素材库后，需要再次确认。

Edge 与 Chrome 的 ID 不同时，分别连接。最多登记八个用户明确输入的 ID；不使用通配来源。更新安装路径或扩展 ID 后重新连接。注册在当前用户的 `HKCU` 中，不需要管理员权限。当前不提供商店上架包。

## 使用

- 网页图片右键 → **保存图片至栈藏**。已有网站权限及已确认素材库时直接采集；否则打开面板确认。
- 网页视频右键 → **保存视频至栈藏**。仅无登录凭据、可直接读取的 MP4/WebM；流媒体、需要登录或读取失败时只保存页面来源及可获取封面，明确提示没有下载视频文件。不绕过 DRM。
- 工具栏按钮 → **选择网页图片**，最多勾选 100 张；可选择当前库的图片文件夹、标签和项目。
- **区域截图**：面板关闭后在网页拖出矩形；按 Escape 取消。截图完成后重新打开面板，确认保存。不要在框选时切换网页。单张截图暂存上限 6 MB。
- **保存页面链接**：只保留来源、标题及可获取的封面，不把网页本身或网页视频当成文件下载。
- 默认进入采集收件箱，媒体原件存入图片库或视频库；收件箱可以打开预览、整理文件夹与标签、加入项目/参考板、创建含来源和媒体引用的学习笔记。
- 软件未运行时扩展启动后台接收；**打开栈藏**按钮显示主窗口。软件已打开时采集不会强制切换页面。
- 扩展显示的是逐项结果；“已暂存，等待处理”不是保存成功。耗时的视频处理可在应用任务中心检查、取消或重试。

## 限制与隐私

- 只在点击采集时读取内容。网站权限按实际选择的资源域名申请；没有后台全站爬取、Cookie/密码/Token 上传或远程服务。
- 图片只接收 PNG/JPEG/WebP/GIF，单文件 25 MB、2500 万像素；视频单文件 512 MB。SVG、AVIF、动态资源无法直接读取时可改用区域截图。
- 不接收内网地址、任意本地路径、外部伪造媒体 ID、远程执行请求。网络跳转默认拒绝；部分 CDN 跳转、防盗链和登录资源可能需要截图替代。
- 本地通信使用 Chrome/Edge Native Messaging。元数据和分块文件先进入当前用户的有界暂存队列，再按素材库 UUID 提交现有后台导入任务。无本地 HTTP 端口。
- 文件去重按 SHA-256；重复不覆盖名称、不移动已有文件夹、不更改已有标签。明确选择项目时可增加项目关联。回收站重复仍提供原条目信息，需先恢复。
- 取消未提交的传输不会导入；已提交到应用的处理任务需要在应用任务中心取消。崩溃中断不会自动重新执行已登记任务。
- 图片读取最多等待 60 秒，视频最多 180 秒；超时显示未确认结果，不会一直卡住。扩展后台被浏览器中断后，会提示检查收件箱或重新采集。
- 下载 URL 只在浏览器内使用；保存的来源地址会清理常见登录、Token、签名参数及片段。请勿采集包含私密内容或网站自定义凭据的页面。
- 文件夹显示父级路径以区分同名目录；目标列表特别大时，只展示有界部分，剩余目标可先采集再在应用中整理。
- 已完成的库内采集记录、媒体和关联随整库备份/恢复/迁移移动；尚未处理的全局暂存队列不包含在整库备份中。请在备份前检查任务中心。

## 手动验收

Edge 和 Chrome 分别验证：首次连接、软件关闭后启动、单图/100 张批量图片、区域截图/取消、公开 MP4/WebM、平台视频链接及封面、去重、任务取消/重试、错误格式、切库、回收站条目、重启、备份恢复。真实网站限制和 Windows 原生窗口行为不能由模拟测试替代。
